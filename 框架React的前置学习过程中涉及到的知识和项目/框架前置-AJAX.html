框架前置-AJAX

AJAX

在页面加载完成后，从Web服务器读取数据

无需重新加载页面即可更新网页

在后台发送数据给Web服务器

001.AJAX工作原理：

1.网页触发事件

2.JS创建XMLHttpRequest对象

3.XMLHttpRequest对象向Web服务器发送请求

4.服务器处理请求

5.服务器向网页发送响应

6.JS读取响应

7.JS执行适当的操作，更新页面等

现代浏览器可以使用FetchAPI来代替XMLHttpRequest对象，同样使用原对

象，也可以使用Fetch一更简单的方式对其执行相同操作

002.XMLHttpRequest对象：可用于后台与Web服务器交换数据，可以更新网页的部分，而不重新加载整个网页

1.创建XMLHttpRequest对象：现代浏览器都有内置的对象

variable = new XMLHttpRequest();

2.定义回调函数：函数作为参数传递给另一个函数

xhttp.onload = function() {

// What to do when the response is ready

}

3.打开XMLHttpRequest对象

4.向服务器发送请求，使用对象的open（）和send（）方法

xhttp.open("GET", "ajax_info.txt");

xhttp.send();

下例为最简单的XMLHttpRequest对象执行流程

// Create an XMLHttpRequest object创建对象

const xhttp = new XMLHttpRequest();

// Define a callback function回调函数

xhttp.onload = function() {

// Here you can use the Data使用数据

}

// Send a request发送请求

xhttp.open("GET", "ajax_info.txt");

xhttp.send();

003.跨域访问：

出于安全原因，现代浏览器不允许跨域访问。

这意味着网页和它尝试加载的 XML 文件必须位于同一台服务器上。

W3Schools 上的示例全部打开位于 W3Schools 域上的 XML 文件。

如果您想在自己的网页上使用上述示例，则您加载的 XML 文件必须位于您自己的服务器上。

004.XMLHttpRequest对象属性及方法：

属性：

onload：定义接收到请求时要调用的函数

onreadystatechange：定义当readyState属性发生变化时调用的函数

readyState：保存XMLHttpRequest的状态

0未初始化请求、1服务器连接已建立、2请求已收到、3正在处理请求、4请求已完成且相应已就绪

responseText：以字符串形式返回响应数据

responseXML：以XML数据返回响应数据

status：返回请求的状态号：200、403、404

statusText：返回状态文本，ok等

方法：

new XMLHttpRequest（）：创建新的XMLHttpRequest对象

abort（）：取消当前请求

getAllResponseHeader（）：返回头部信息

getResponseHeader（）：返回特定的头部信息

open（method，url，async，user，psw）规定请求

method请求类型Get或Post、url文件位置、async异步true或同步false、user可选用户名、psw可选密码

send（）向服务器发送请求，用于GET请求

send（string）向服务器发送请求，用于POST请求

setRequestHeader（）：将标签/值对添加到要发送的标头

onload属性：使用对象时，在onload属性中定义回调函数

xhttp.onload = function() {
  document.getElementById("demo").innerHTML = this.responseText;
}
xhttp.open("GET", "ajax_info.txt");
xhttp.send();

多个回调函数：网站存在多个AJAX任务，应该创建一个执行XMLHttpRequest对象的函数，为多个AJAX任务创建一个回调函数，函数调用包含URL以及响应准备就绪时要调用的函数

loadDoc("url-1", myFunction1);

loadDoc("url-2", myFunction2);

function loadDoc(url, cFunction) {
  const xhttp = new XMLHttpRequest();
  xhttp.onload = function() {cFunction(this);}
  xhttp.open("GET", url);
  xhttp.send();
}

function myFunction1(xhttp) {
  // 这里是动作
}
function myFunction2(xhttp) {
  // 这里是动作
}

onreadystatechange属性：保存了XMLHttpRequest的状态，当readyState状态发生改变时，会调用一次该属性

例子：当readyState为4且status为200时响应

function loadDoc() {
  const xhttp = new XMLHttpRequest();
  xhttp.onreadystatechange = function() {
    if (this.readyState == 4 && this.status == 200) {
      document.getElementById("demo").innerHTML =
      this.responseText;
    }
  };
  xhttp.open("GET", "ajax_info.txt");
  xhttp.send();
}
onreadystatechange 事件被触发了四次（1-4），每次 readyState 变化一次

005.XMLHttpRequest：请求

XMLHttpRequest对象用于从服务器请求数据

向服务器发送请求：使用XMLHttpRequest对象的open和send方法

例子：

xhttp.open("GET", "ajax_info.txt", true);

xhttp.send();

  • open（method，url，async，user，psw）规定请求

    method请求类型Get或Post、url文件位置、async异步true或同步false、user可选用户名、psw可选密码

  • send（）向服务器发送请求，用于GET请求
  • send（string）向服务器发送请求，用于POST请求

URL-服务器上的文件地址，可以是任意类型文件或服务器脚本文件

异步：服务器请求应该异步发送

open（）方法的async参数应该设置为true，这样JS不必等待服务器响应，可以同时执行其他脚本并在响应准备好后处理响应

如：xhttp.open（“GET”，“example.asp”，true）

GET和POST：

GET比POST要更简单、更快，多数情况使用GET

下面特殊情况使用POST

  • 缓存文件不是一个选项，（更新服务器上的文件或数据库
  • 向服务器发送大量数据，（POST没有大小限制
  • 发送用户输入，可能包含未知字符，POST比GET安全

GET请求：

例子：简单的GET请求，可能会得到缓存

xhttp.open("GET", "demo_get.asp");

xhttp.send();

例子：通过向URL中添加ID

xhttp.open("GET", "demo_get.asp?t=" + Math.random());

xhttp.send();

例子：使用GET发送信息，将信息添加到URL中

xhttp.open("GET", "demo_get2.asp?fname=Henry&lname=Ford");

xhttp.send();

POST请求：

例子：简单的POST请求

xhttp.open（“POST“，”demo_post.asp“）；

xhttp.send（）；

例子：向HTML表单一样POST数据，需要添加HTTP标头setRequestHeader（），并在send（）方法中指定要发送的数据

xhttp.open（”POST“，”ajax_test.asp“）；

xhttp.setRequestHeader（”Content-type“，”application/x-www-form-urlencoded“）；

xhttp.send（”fname=Henry&lname=Ford“）；

setRequestHeader（header，value）：要添加的请求头的名称，请求头的值，均为字符串

同步请求：不建议使用

若进行同步请求，请将open（）方法中的第三个参数async更改为false

xhttp.open（”GET“，”ajax_test.txt“,false）

006.AJAX-服务器响应：

服务器响应属性：

  • responseText：以字符串形式返回服务器响应

document.getElementById("demo").innerHTML = xhttp.responseText;

  • reponseXML：以XML DOM对象的形式返回服务器响应

例子：

const xmlDoc = xhttp.responseXML;

const x = xmlDoc.getElementsByTagName("ARTIST");

let txt = "";

for (let i = 0; i < x.length; i++) {

txt += x[i].childNodes[0].nodeValue + "<br>";

}

document.getElementById("demo").innerHTML = txt;

xhttp.open("GET", "cd_catalog.xml");

xhttp.send();

其他服务器响应方法：

  • getResponseHeader（）：返回服务器响应的所有标头信息

const xhttp = new XMLHttpRequest();

xhttp.onload = function() {

document.getElementById("demo").innerHTML =

this.getAllResponseHeaders();

}

xhttp.open("GET", "ajax_info.txt");

xhttp.send();

  • getAllResponseHeaders（）：返回服务器响应的特定的标头信息

const xhttp = new XMLHttpRequest();

xhttp.onload = function() {

document.getElementById("demo").innerHTML =

this.getResponseHeader("Last-Modified");

}

xhttp.open("GET", "ajax_info.txt");

xhttp.send();

007.AJAX与XML文件进行交互式通信

用户点击”获取CD信息“按钮时，loadDoc（）功能执行

创建一个新的对象，添加在服务器响应准备就绪时要执行的函数，并将请求发送到服务器

服务器响应准备就绪时，构建一个HTML表，从XML文件中提取元素，最后使用填充由XML数据的HTML表来更新元素”demo“

function loadDoc() {

const xhttp = new XMLHttpRequest();

xhttp.onload = function() {myFunction(this);}

xhttp.open("GET", "cd_catalog.xml");

xhttp.send();

}

function myFunction(xml) {

const xmlDoc = xml.responseXML;

const x = xmlDoc.getElementsByTagName("CD");

let table="<tr><th>Artist</th><th>Title</th></tr>";

for (let i = 0; i <x.length; i++) {

table += "<tr><td>" +

x[i].getElementsByTagName("ARTIST")[0].childNodes[0].nodeValue +

"</td><td>" +

x[i].getElementsByTagName("TITLE")[0].childNodes[0].nodeValue +

"</td></tr>";

}

document.getElementById("demo").innerHTML = table;

}
