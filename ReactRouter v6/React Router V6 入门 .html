React Router V6 入门

React Router，简单来说就是一个帮助处理React应用程序中导航和路由的库，用于管理React中路由的路由工具。

常用的连接a标签，在应用程序中导航，当想要在导航是保留应用程序的当前状态时，就会出现问题，普通的连接通常会触发页面刷新来显示组件，进而破坏用户体验

React Router允许在应用程序中定义不同的路由，并连接到各自的组件，无需重新加载页面，这个方法使得React Router能轻松更新页面上的内容，使网站更像一个原生应用程序

React Router还有其他特点，比如创建复杂的导航、无缝的页面导航结构、以及对动态URL的支持

理解路由概念：

  • History Stack：React Router只能使用HTML5 History API来跟踪用户的导航历史，当用户访问新的URL时，React Router将该URL推送到历史堆栈中，当用户导航到其他URL时，他们也会被推送到堆栈中，这就是React Router在不刷新页面情况下来回导航路由的方式。
  • Location：指的是浏览网址时当前的URL，他是历史堆栈中的顶级URL，以及React Router如何动态更改显示的内容以匹配正确的URL
    • 在一些浏览器中，可以长按返回按钮查看历史记录中的所有URL列表

浏览器路由及其用途：

  • React使用组件和Hook，React Router也是，而React Router提供的关键组件就像body元素对于网站一样，BrowserRouter就是。他为网站内所有可能的路由提供了基础
    • 注意，BrowserRouter可以放置在应用程序的任何位置，通常将BrowserRouter放置在组件树顶部，来包裹整个应用程序的组件
  • 回到项目的index.js中，实现BrowserRouter，将整个App组件包裹其中，
    import { BrowserRouter } from "react-router-dom";

    const root = ReactDOM.createRoot(document.getElementById("root"));
    root.render(
    <React.StrictMode>
    <BrowserRouter>
    <App />
    </BrowserRouter>
    </React.StrictMode>
    );

  • 通过<BrowserRouter /> App组件，路由功能在App组件中的所有组件中都可用

使用Routes和Route：

  • 完全掌握React Router中的Routes组件的作用，首先了解Route的作用
  • Route组件：
    • 该组件定义了一个特定的URL路径，并指向在访问该URL路径时应该渲染的组件
    • 该组件由两个主要属性
      • Path：此属性接受一个字符串，用于指定Route的路径，
        • 例如，Route，path属性设置为“/eras”，当URL变为“https：//historyApp.com/eras”时，触发该Route组件
      • Element：当path属性中的路径被访问时，该属性被分配给要渲染的React组件，
        • 如果访问/eras路径，则<Eras />组件将在页面上展示
          • <Route path=”/eras” element={<Eras />}>

  • Routes组件：
    • Routes是Route组件的容器组件，她负责检查当前URL位置，并将其与子Route组件中指定的路径进行比较，找到匹配项
    • 在Routes内，可以嵌套所有的Route组件，然后再浏览网站时，Routes会获取当前的URL，并将其与每个子路由组件进行匹配，已找到与之对应的最佳组件
  • 在历史应用项目中设置Routes和Route步骤如下
    import { Routes, Route } from 'react-router-dom';

    export default function App() {
    return (
    <Routes>
    <Route path="/" element={<Home />} />
    <Route path="/eras" element={<Eras />} />
    </Routes>
    );
    }

    • 首先从react-route-dom包中导入Routes和Route组件
    • 然后再App组件内部，Routes组件限制了不同的Route组件
    • 第一个路由的路径设置为”/“，当访问时将渲染Home组件，这个默认路由将始终在访问根URL时渲染
    • 该/eras路由与Eras组件相关联，这意味着每当URL路径与/eras匹配时，将显示<Eras />组件内容
  • 再地址栏中的根URL后添加/eras时，React Router使用Routes组件匹配具有路径设置为/eras的确切Route，一旦找到，将渲染在匹配的Route的element属性中定义的组件，这种情况下，时<Eras />组件。

404页面：

  • 404错误时一个HTTP状态码，当请求的资源或页面无法找到时显示出来，可能发生再用户输入了一个不存在的URL时
  • React Router包含了一种处理404错误的方式，当访问一个未定义的网站时，会渲染一个自定义组件，要处理React Router中的404错误，请创建一个route，将其path属性设置为*，并将其element属性设置为应该呈现的错误组件。
    • 首先创建一个错误404组件
      function Error404() {
      return (
      <div>
      <h1>404 — Page Not Found</h1>
      <a href="/">Take me back!</a>
      </div>
      );
      }
    • 然后创建一个route来渲染<Error404 />
      export default function App() {
      return (
      <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/eras" element={<Eras />} />
      {/* 404 page
      /}
      <Route path="
      " element={<Error404 />} />
      </Routes>
      );
      }
      • 可以处理网站中出现的意外

路由之间的连接：

  • 目前为止，只讨论了如何通过手动在地址栏中输入URL来访问路由，但是并不理想，用户不可能记住每个页面的确切URL
  • a标签通常用于解决这个问题，但他有限制，比如重渲染页面，为了绕过这些限制React Router使用了Link组件
  • 在React Route中,Link时路由导航的主要方式，连接组件在底层使用a标签，但通过阻止默认页面重新加载来增强它，
  • 相反Link将to属性中的URL推送到历史堆栈，然后Routes组件找到具有相同URL的匹配route并显示相关插件
    • React Route使用Link组件而不是a标签，因为Link被设计用于防止页面重新加载，保留应用程序状态，并在路由之间提供了无缝导航。
  • 这是在历史网站中使用Link的方法，在App.js中创建导航组件
    import { Link } from "react-router-dom";

    function Nav() {
    return (
    <ul className='nav'>
    <li>
    <Link to='/'>Home</NavLink>
    </li>
    <li>
    <Link to='/eras'>Eras</NavLink>
    </li>
    </ul>
    );
    }

    • 首先从React-route-dom导入Link组件，然后创建一个功能组件Nav，用作历史网站的导航，这个Nav组件遵循了典型导航菜单的结构，只是使用了Link组件而不是a标签
    • 每个<Link />都有一个特定的路径分配给to属性，这位Link设置了目标路由，因此，当点击任何这些链接时，React Router会从to属性获取URL，匹配正确的route路径，并渲染指定的组件
  • 由于Nav组件应在所有页面上可见，将其放在App组件顶部
    export default function App() {
    return (
    <>
    <Nav />
    <Routes>
    <Route path='/' element={<Home />} />
    <Route path='/eras' element={<Eras />} />
    <Route path='*' element={<Error404 />} />
    </Routes>
    </>
    );
    }
  • 为其添加简单样式来增加吸引力，App.css
    a {

    a:hover {

NavLink与Link不同：(都需要在react-router-dom中引入)

  • React Router有一个叫做NavLink的组件，类似于Link，但主要用于处理菜单导航链接，不同于Link组件，后者可以用于任何类型的连接
  • NavLink和Link之间的主要区别就是，NavLink可以检测自身是否处于活动状态，当NavLink检测到自身处于活动状态时，默认为组件添加一个active类
  • 总体来说，NavLink在创建导航菜单连接时比Link组件强大

嵌套路由：

  • 在React Router中，嵌套可以被视为在路由之间建立父子连接，这可以用来组织共享相同的URL路径的路由
  • 嵌套路由使用Route组件作为父路由，另一个Route组件用于定义父路由内部的子路由，因此只有在父路由上时才能渲染子路由
  • 在历史网站上，可以在时代部分找到中世纪和数字化这两个可用的时代类别，因此要访问这些时代的详细信息，可以把他们嵌套在/eras路径中。
    • 创建Medieval和Digital组件
      function MedievalEra() {
      return (
      <div>
      <hr />
      <h3>The Medieval Era</h3>
      <p>Lorem ipsum dolor sit amet.</p>
      </div>
      );
      }

      function DigitalEra() {
      return (
      <div>
      <hr />
      <h3>The Digital Era</h3>
      <p>Lorem ipsum dolor sit amet.</p>
      </div>
      );
      }

    • 并在App组件中使用
      export default function App() {
      return (
      <>
      <Nav />
      <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/eras" element={<Eras />}>
      <Route path="medieval" element={<MedievalEra />} />
      <Route path="digital" element={<DigitalEra />} />
      </Route>
      <Route path="*" element={<Error404 />} />
      </Routes>
      </>
      );
      }
  • 此时导航到/eras/medieval或/eras/digital应该分别呈现，两个对应的组件，但是他不会按预期呈现
  • 因为React Router不知道如何放置嵌套组件，为解决问题，React Router提供了应该Outlet组件，可以明确指出嵌套路由组件应该放置在哪里
    • 导入Outlet组件
      • import {Outlet} from “react-router-dom”
    • 将Outlet组件放置在Eras组件内部
      function Eras() {
      return (
      <div>
      <h1>The Eras of Time</h1>
      <ul>
      <li>
      <Link to="medieval">Medieval</Link>
      </li>
      <li>
      <Link to="digital">Digital</Link>
      </li>
      </ul>
      <Outlet />

      </div>
      );
      }

      • 代码中，a标签被替换为Link组件，并将相应的路径放置在to属性中
      • 在此之后，<Outlet />组件被放置在下方，这是这是嵌套路由组件将被渲染的位置
  • 嵌套路由有各种用途，比如层次化组织路由、代码效率、提高性能等

动态路由与useParams：

  • 动态路由是一个概念，允许创建不是硬编码的路由，而是根据用户操作或数据生成的路由
  • React Router使用Route组件和useParams Hook来处理动态路由
    • 设置动态路由时，在route组件的path属性中使用占位符（使用冒号：表示）
      • <Route path=”/eras/：type“ element={<EraType />} />
        • 对于Route的占位符是“：type”，表示type参数的值会动态生成
    • React Router提供了usePramas的Hook，用于有效处理动态路由
      • useParams Hook返回一个包含来自Route组件的动态之的对象，该值可以在负责渲染动态内容的组件中使用
        import { useParams } from "react-router-dom";

        function EraType() {
        const { type } = useParams();

        return (
        <div>
        <hr />
        <h3>The {type} Era</h3>
        </div>
        );
        }

      • App组件变化
        export default function App() {
        return (
        <>
        <Nav />
        <Routes>
        <Route path='/' element={<Home />} />
        <Route path='/eras' element={<Eras />}>
        <Route path='medieval' element={<MedievalEra />} />
        <Route path='digital' element={<DigitalEra />} />
        {/* Dynamic route
        /}
        <Route path=':type' element={<EraType />} />
        </Route>
        <Route path='
        ' element={<Error404 />} />
        </Routes>
        </>
        );
        }
  • 有了动态Route，当你在/eras路由内导航时，像/eras/ancient这样，值“ancient”为动态路径，可以通过从useParams提取的type变量进行访问
    • 由于嵌套的路由结构，<Eras />组件内的<EraType />组件被渲染
  • 这是useParams的基本例子，这个Hook可以用于其他方式，比如从API中获取类似的动态数据

使用useRoutes Hook：

  • React Router提供了另一个Hook，是useRoutes Hook
  • 这个Hook知识React Router中用于结构化Routes和Route的另一种方式，他的工作原理是：不使用React组件的形式（JSX），而是使用JS对象
    • 在App.js中，这是我们如何构建Routes和Route组件的结构
      export default function App() {
      return (
      <>
      <Nav />
      <Routes>
      <Route path='/' element={<Home />} />
      <Route path='/eras' element={<Eras />}>
      <Route path='medieval' element={<MedievalEra />} />
      <Route path='digital' element={<DigitalEra />} />
      <Route path=':type' element={<EraType />} />
      </Route>
      <Route path='*' element={<Error404 />} />
      </Routes>
      </>
      );
      }
      • 使用useRoutes Hook代码重构如下
        import { useRoutes } from 'react-router-dom';

        export default function App() {
        const routes = useRoutes([
        {
        path: "/",
        element: <Home />,
        },
        {
        path: "/eras",
        element: <Eras />,
        children: [
        {
        path: "medieval",
        element: <MedievalEra />,
        },
        {
        path: "digital",
        element: <DigitalEra />,
        },
        {
        path: ":type",
        element: <EraType />,
        },
        ],
        },
        {
        path: "*",
        element: <Error404 />,
        },
        ]);

        return (
        <>
        <Nav />
        {routes}
        </>
        );
        }

  • useRoutes Hook从react-router-dom导入，然后，一个路由对象数组被传递给useRoutes
    • 每个路由对象都有一个path和element属性，用于指定路径和在路由匹配时应该渲染的组件
  • 所有，在useRoutes Hook或Routes和Route组件之间的选择归结为个人爱好，选择适配风格即可

学习React Router时前端开发者迈出的重要一步，使用该工具，在应用中管理路由导航和创建良好结构化的路由系统更简单。
