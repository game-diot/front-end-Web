路由：

  • 配置路由
    • 路由在app/routes.ts中配置，包含两个必须的部分
      • 一个用于匹配URL的URL模式
      • 一个定义其行为的路由模块的文件路径
        • app/routes.ts
          导入两个内容：TS数据类型的定义，仅用于描述路由配置结构即类型检查；工厂函数route，用于创建单个路由对象
          import {
          type RouteConfig,
          route,
          } from "@react-router/dev/routes";
          默认导出路由对象
          export default [

          接收参数前者表示匹配的URL路径模式；后者位对应的模块文件路径，通常为包含React组建的文件
          route("some/path", "./some/file.tsx"),
          // pattern ^ ^ module file
          ]
          satisfies RouteConfig;

          TS操作，确保数组符合RouteConfig类型，不影响推断的具体类型，在开发阶段提供类型检查，保证路由结构正确，不会强制类型转换。
        • 更大的URL配置示例
          import {
          type RouteConfig,
          route,
          index,
          layout,
          prefix,
          } from "@react-router/dev/routes";

          export default [
          index("./home.tsx"),
          route("about", "./about.tsx"),

          layout("./auth/layout.tsx", [
          route("login", "./auth/login.tsx"),
          route("register", "./auth/register.tsx"),
          ]),

          ...prefix("concerts", [
          index("./concerts/home.tsx"),
          route(":city", "./concerts/city.tsx"),
          route("trending", "./concerts/trending.tsx"),
          ]),
          ] satisfies RouteConfig;
        • 使用文件命名约定来定义路由，@react-router/fs-routes包提供了文件系统路由约定，可以根据需要组合不同的路由约定
          import {
          type RouteConfig,
          route,
          } from "@react-router/dev/routes";
          import { flatRoutes } from "@react-router/fs-routes";

          export default [
          route("/", "./home.tsx"),

          ...(await flatRoutes()),
          ] satisfies RouteConfig;
  • 路线模块
    • 引用的routes.ts文件定义了每个路由的行为
      • app/routes.ts
        route("teams/:teamId", "./team.tsx"),
        // route module ^^^^^^^^
      • 路线模块的示例
        • app/team.tsx
          TS类型导入，Route提供类型安全/类型推导功能。
          // provides type safety/inference
          import type { Route } from "./+types/team";

          定义loader函数，预加载数据函数，在组件渲染前调用
          Route.LoaderArgs，Route的一个参数类型，包含paramsUrl参数对象/request请求对象。

          // provides `loaderData` to the component
          export async function loader({ params }: Route.LoaderArgs) {

          params.teamId为获取当前路径中的动态参数，例如/teams/123中的teamId为123
          let team = await fetchTeam(params.teamId);

          返回数据通过loaderData传递给组件
          return { name: team.name };
          }

          // renders after the loader is done
          export default function Component({
          loaderData,
          }: Route.ComponentProps) {
          return <h1>{loaderData.name}</h1>;
          }
          URL: /teams/123
          1. 加载 route/team.tsx
          1. 执行 export async loader()
            → 获取 teamId = "123"
            → 调用 fetchTeam(teamId)
            → 返回 { name: "Red Bull Racing" }
          1. 渲染 Component 组件
            → 通过
            loaderData.name 显示标题
        • 路由模块具有很多功能，例如操作、标头和错误边界等
  • 嵌套路由
    • 路由可以嵌套在父路由中
      • app/routes.ts
        import {
        type RouteConfig,
        route,
        index,
        } from "@react-router/dev/routes";

        export default [
        // parent route
        route("dashboard", "./dashboard.tsx", [
        // child routes
        index("./home.tsx"),
        route("settings", "./settings.tsx"),
        ]),
        ] satisfies RouteConfig;
        • 父级的路径会自动包含在子级中，因此配置会创建/dashboard和/dashboard/setting两个URL
    • <Outlet />子路由通过父路由进行渲染
      • app/dashboard.tsx
        import { Outlet } from "react-router";

        export default function Dashboard() {
        return (
        <div>
        <h1>Dashboard</h1>
        {/* will either be home.tsx or settings.tsx */}
        <Outlet />
        </div>
        );
        }
  • 根路由：
    • 每个routes.ts路线都嵌套在app/root/tsx特殊模块内
  • 布局路线：
    • 使用layout布局路由会为其子路由创建新的嵌套，但他们不会向URL添加任何段，类似于根路由，但它们可以在任何级别添加
      • app/routes.ts
        import {
        type RouteConfig,
        route,
        layout,
        index,
        prefix,
        } from "@react-router/dev/routes";

        export default [
        layout("./marketing/layout.tsx", [
        index("./marketing/home.tsx"),
        route("contact", "./marketing/contact.tsx"),
        ]),
        ...prefix("projects", [
        index("./projects/home.tsx"),
        layout("./projects/project-layout.tsx", [
        route(":pid", "./projects/project.tsx"),
        route(":pid/edit", "./projects/edit-project.tsx"),
        ]),
        ]),
        ] satisfies RouteConfig;
        • home.tsx并且contact.tsx被渲染到marketing/layout.tsx出口，而不会创建新的URL路径
        • project.tsx和edit-project.tsx会被渲染到projects/project-layout.tsx出口出，/projects/：pid和/projects/：pid/edit就不会渲染到projects/home.tsx
  • 索引路由：
    • index（componentFile）
    • 索引路由在其父级的URL出呈现到其父级的Outlet中（就像默认子路由一样）
      • app/routes.ts
      import {
      type RouteConfig,
      route,
      index,
      } from "@react-router/dev/routes";

      export default [
      // renders into the root.tsx Outlet at /
      index("./home.tsx"),
      route("dashboard", "./dashboard.tsx", [
      // renders into the dashboard.tsx Outlet at /dashboard
      index("./dashboard-home.tsx"),
      route("settings", "./dashboard-settings.tsx"),
      ]),
      ] satisfies RouteConfig;

      • 索引路由不能有子路由
  • 路由前缀：
    • 使用prefix，可以向一组路由添加路径前缀，而无需引入父路由文件，
      • app/routes.ts
        import {
        type RouteConfig,
        route,
        layout,
        index,
        prefix,
        } from "@react-router/dev/routes";

        export default [
        layout("./marketing/layout.tsx", [
        index("./marketing/home.tsx"),
        route("contact", "./marketing/contact.tsx"),
        ]),
        ...prefix("projects", [
        index("./projects/home.tsx"),
        layout("./projects/project-layout.tsx", [
        route(":pid", "./projects/project.tsx"),
        route(":pid/edit", "./projects/edit-project.tsx"),
        ]),
        ]),
        ] satisfies RouteConfig;

  • 动态细分：
    • 如果路径段以：开头，则它将变为动态段，当路由与URL匹配时，动态段将从URL中解析出来，兵团法国params给其他路由API
      • app/routes.ts
        • route（“teams/：teamId”，“./team.tsx”）
      • app/team.tsx
        import type { Route } from "./+types/team";

        export async function loader({ params }: Route.LoaderArgs) {
        // ^? { teamId: string }
        }

        export default function Component({
        params,
        }: Route.ComponentProps) {
        params.teamId;
        // ^ string
        }

        • 一个路径可以有多个动态段
          • app/routes.ts
            • route（”c/categoryId/p/productId“，”./product.tsx“）
          • app/product.tsx
            import type { Route } from "./+types/product";

            async function loader({ params }: LoaderArgs) {
            // ^? { categoryId: string; productId: string }
            }

  • 可选段：
    • 可以通过在路线段末尾添加？，来使路线段成为可选的
      • app/routes.ts
        • route（“：lang？/categories”，“./categories.tsx”）
      • 可以有可选的静态段
        • app/routes.ts
          • route（“users/：userId/edit？”，“./user.tsx”）
  • 渐
    • 也成为“catchall”和“star”段，如果路由路径模式以/*结尾，则它将匹配/之后的任何字符，包括/其他字符
      • app/routes.ts
        • route（files/*“，”./files.tsx“）
      • app/files.tsx
        export async function loader({ params }: Route.LoaderArgs) {
        // params["*"] will contain the remaining URL after files/
        }
      • 可以结构*，之需要为其指定一个新名称即可，一个常见的名称是splat
        • const{“*”：splat} = params
  • 组件路由：
    • 可以使用与组件树中任何位置的元素匹配URL的组件
      import { Routes, Route } from "react-router";

      function Wizard() {
      return (
      <div>
      <h1>Some Wizard with Steps</h1>
      <Routes>
      <Route index element={<StepOne />} />
      <Route path="step-2" element={<StepTwo />} />
      <Route path="step-3" element={<StepThree />} />
      </Routes>
      </div>
      );
      }

    • 注意，路由不参与数据加载、操作、代码拆分或任何其他路由模块功能，因此他们的用例比路由模块比例更有限。

路由模块：

  • 介绍：
    • 其中引用的文件routes.ts成为路由模块
      • app/routes.ts
        • route（”teams/：teamId“，”./team.tsx“）
    • 路由模块是React Router框架功能的基础，定义功能如下
      • 自动代码分割
      • 数据加载
      • 行动
      • 重新验证
      • 错误边界
      • 以及更多
        • 如下简述每个路由模块功能
  • 成分（default）：
    • 路由模块中默认导出default，定义了路由匹配时将呈现的组件
      • app/routes/my-route.tsx
        export default function MyRouteComponent() {
        return (
        <div>
        <h1>Look ma!</h1>
        <p>
        I'm still using React Router after like 10 years.
        </p>
        </div>
        );
        }
  • 传递给组件的工具：
    • 组件渲染时，会传入React Router自动生成的props，props包括
      • loaderDate：在这路由模块包含loader函数返回的数据
      • actionData：在这路由模块包含action函数返回的数据
      • params：包含路由参数的对象（如果有）
      • matches：当前路线树中所有匹配的数组。
        • 可以使用这些props来代替useLoaderData或useParams之类的Hook，他们会根据路由自动正确输入
  • 使用工具：
    • app/routes/my-route-with-default-params.tsx
      import type { Route } from "./+types/route-name";

      export default function MyRouteComponent({
      loaderData,
      actionData,
      params,
      matches,
      }: Route.ComponentProps) {
      return (
      <div>
      <h1>Welcome to My Route with Props!</h1>
      <p>Loader Data: {JSON.stringify(loaderData)}</p>
      <p>Action Data: {JSON.stringify(actionData)}</p>
      <p>Route Parameters: {JSON.stringify(params)}</p>
      <p>Matched Routes: {JSON.stringify(matches)}</p>
      </div>
      );
      }
