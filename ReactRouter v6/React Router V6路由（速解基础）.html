React Router V6路由（速解基础）

React-Router是什么：

  • 许多现代网站时有一个页面组成，因为包含像独立页面一样渲染的组件，会看起来像一个页面。
  • 这些被称为SPA-单页应用程序。核心部分中是React-Router的作用
  • React-Router作用是根据URL中使用的路由（/代表主页，/about代表相关页面等等），根据条件渲染某些组件内容
    • 例如使用React-Router将www.knit-with-scrimba.com/连接到www.knit-withscrimba.com/about 或者连接到 www.knit-with-scrimba.com/shop

使用React Router：

  • 使用NPM安装
    • npm install react-router-dom
  • 需要从react-router-dom包中导入BrowserRouter、Route和Switch
    • import React，{Component} from ‘react’
    • import {BrowserRouter，Route，Switch} from ‘react-router-dom’
  • 在示例中，将登陆页面与另外两个页面连接起来，Shop和About页面
  • 首先设置应用程序和React Router一起工作，所有被渲染的东西都放在><BrowserRouter>元素中，所以先把App包在这些元素里面，这个组件设置显示所有提供给他的各种组件逻辑
    • index.js
      ReactDOM.render(
    <BrowserRouter>
        <App />
    </BrowserRouter>,
    document.getElementById('root')
)
  • 接下来在App组件中，添加Switch元素（用于开放和关闭标签）。确保一次只渲染一个组件，如果不使用，可以默认为Error组件
    function App() {
    return (
        <main>
            <Switch>

            </Switch>
        </main>
    )
}
  • 然后添加<Route>标签，这些是组件之间的连接，应该放在<Switch>标签内。
    • 要告诉<Route>标签加载哪个组件，只需要添加一个path属性和想用component属性加载的组件名称
      • <Route path=‘/’ component={Home} />
  • 许多主页的URL是网站名称后面加一个”/“，例如，www.knit-with-scrimba.com/。
    • 这种情况下，在Route标签中加入exact，这是因为其他的URL也包含‘/’，所有如果不告诉应用程序它只需要寻找‘/’，他就回家再第一个与路由匹配的URL，相对应或出现bug
      function App() {
    return (
        <main>
            <Switch>
                <Route path="/" component={Home} exact />
                <Route path="/about" component={About} />
                <Route path="/shop" component={Shop} />
            </Switch>
        </main>
    )
}
  • 现在将组件导入到应用程序中，可以将其放在一个单独的component文件中，保证代码的清晰可读性
    import Home from './components/Home';
import About from './components/About';
import Shop from './components/Shop';
  • 前面提到的不管，如果用户输入错误的URL，就会加载，这就像一个普通的<Router>标签，但是没有路径，错误组件包含<h1>Oops! Page not found!</h1>不要忘记将其导入到应用程序中
    function App() {
    return (
        <main>
            <Switch>
                <Route path="/" component={Home} exact />
                <Route path="/about" component={About} />
                <Route path="/shop" component={Shop} />
                <Route component={Error} />
            </Switch>
        </main>
    )
}
  • 目前为止，网站只能通过输入URL进行导航，为了给网站添加可点击的连接，使用React Router的link元素，设置了一个新的Navbar组件，不要忘记把新组件导入到应用程序中。
  • 现在为应用程序中每个组件添加一个Link，并使用to=‘URL’来连接他们
    function Navbar() {
  return (
    <div>
      <Link to="/">Home </Link>
      <Link to="/about">About Us </Link>
      <Link to="/shop">Shop Now </Link>
    </div>
  );
};
  • 现在网站右列可点击的连接，单页应用程序可以导航了。
  • 在React应用程序中轻松导航，忘记毛标签，添加React Router可以使结果很清晰，使添加删除页面更容易。
