框架-React基础-添加交互（概述）

添加交互：

界面上的控件会根据用户的输入而更新，例如点击按钮切换轮播图的展示，在React中，随时间变化的数据被称为状态state，可以向任何组件添加状态，并按需更新。

响应事件：

  • React允许向JSX中添加事件处理程序，事件处理程序是自己制定的函数，将在用户交互时被处罚，如点击、悬停、聚焦在表单输入框上等等。
    • 例如<button>等内置组件只支持内置浏览器时间，如onClick。但是可以创建自己的组件，并给事件处理程序props指定任何特定与应用的名称，可以任意命名
      默认导出App组件，返回一个Toolbar组件，指定Toolbar组件的参数为alert
      export default function App() {
      return (
      <Toolbar
      onPlayMovie={() => alert('Playing!')}
      onUploadImage={() => alert('Uploading!')}
      />
      );
      }

      指定Toolbar组件，返回两个Button组件，指定点击触发参数为onPlayMovie和onUploadImage两个函数，button的内容为play和upload两个参数
      function Toolbar({ onPlayMovie, onUploadImage }) {
      return (
      <div>
      <Button onClick={onPlayMovie}>
      Play Movie
      </Button>
      <Button onClick={onUploadImage}>
      Upload Image
      </Button>
      </div>
      );
      }

      指定Button组件，返回一个button，点击触发为参数的函数，button的内容为参数的children
      function Button({ onClick, children }) {
      return (
      <button onClick={onClick}>
      {children}
      </button>
      );
      }

State：记忆组件：

  • 组件通常需要根据交互来改变屏幕上的内容，例如在表单中键入更新输入栏，在轮播图上点击下一个改变图片，点击购买将产品放入购物车等等。
  • 组件需要记住一些东西，例如当前的输入值，当前的图片，购物车状态等等。
  • 这种特定于组件的记忆被称为状态state。
  • 可以使用useState的Hook为组件添加状态，Hook是能够让组件使用React功能的特殊函数（state是功能之一）
  • useState的Hook让你声明一个状态变量，它接收初始状态并返回一对值：当前状态和一个让你更新状态的设置函数
    const [index, setIndex] = useState(0);

    const [showMore, setShowMore] = useState(false);

  • 下例为一个图库，点击更新状态，data数据自定
    导入需要的组件和功能库
    import { useState } from 'react';
    import { sculptureList } from './data.js';

    默认导出div展示框架
    export default function Gallery() {
    const [index, setIndex] = useState(0);
    const [showMore, setShowMore] = useState(false);
    定义两个状态
    const hasNext = index < sculptureList.length - 1;

    定义状态index的设置函数
    function handleNextClick() {
    if (hasNext) {
    setIndex(index + 1);
    } else {
    setIndex(0);
    }
    }

    定义状态showmore的设置函数
    function handleMoreClick() {
    setShowMore(!showMore);
    }

    let sculpture = sculptureList[index];
    return (
    <>
    <button onClick={handleNextClick}>
    Next
    </button>
    <h2>
    <i>{sculpture.name} </i>
    by {sculpture.artist}
    </h2>
    <h3>
    ({index + 1} of {sculptureList.length})
    </h3>
    <button onClick={handleMoreClick}>
    {showMore ? 'Hide' : 'Show'} details
    </button>
    {showMore && <p>{sculpture.description}</p>}
    <img
    src={sculpture.url}
    alt={sculpture.alt}
    />
    </>
    );
    }

渲染和提交：

  • 在组建显示在屏幕上之前，必须由React进行渲染
  • 请求和服务UI的过程有三个步骤（以厨房上菜为例）
    • 触发渲染（食客将订单送到厨房）
    • 渲染组件（厨房做菜）
    • 提交到DOM（将菜给顾客）

State状态：类似快照：

  • 与普通的JS变量不同，React状态state的行为更像一个快照，设置他并不改变已有的状态变量，而是重新触发一次渲染。
    console.log(count); // 0

    setCount(count + 1); // 请求用 1 重新渲染

    console.log(count); // 仍然是 0！

  • React这样运行为了帮助避免bug，下例为聊天应用程序
    import { useState } from 'react';

    export default function Form() {
    const [to, setTo] = useState('Alice');
    const [message, setMessage] = useState('Hello');

    function handleSubmit(e) {
    e.preventDefault();
    setTimeout(() => {
    alert(`You said ${message} to ${to}`);
    }, 5000);
    }

    return (
    <form onSubmit={handleSubmit}>
    <label>
    To:{' '}
    <select
    value={to}
    onChange={e => setTo(e.target.value)}>
    <option value="Alice">Alice</option>
    <option value="Bob">Bob</option>
    </select>
    </label>
    <textarea
    placeholder="Message"
    value={message}
    onChange={e => setMessage(e.target.value)}
    />
    <button type="submit">Send</button>
    </form>
    );
    }

把一系列state更新加入对列

  • 从例子触发，下例点击一次【+3】，只能增加一次分数
    import { useState } from 'react';

    export default function Counter() {
    const [score, setScore] = useState(0);

    function increment() {
    setScore(score + 1);
    }

    return (
    <>
    <button onClick={() => increment()}>+1</button>
    <button onClick={() => {
    increment();
    increment();
    increment();
    }}>+3</button>
    <h1>Score: {score}</h1>
    </>
    )
    }
    • state如同一张快照，设置状态会请求一个新的重新渲染，但不会在已经运行的代码中更改他。在调用setScore（score + 1 ），score值仍为0
    • 理解为在setState时候，使用的state，一直都会是触发事件时的值
    • 好比点击按钮时state=0，点击按钮会触发三次函数，这三次函数都会以state=0为参数
      console.log(score); // 0
      setScore(score + 1); // setScore(0 + 1);
      console.log(score); // 0
      setScore(score + 1); // setScore(0 + 1);
      console.log(score); // 0
      setScore(score + 1); // setScore(0 + 1);
      console.log(score); // 0
    • 可以在设置状态时传递一个更新其函数，来解决这个问题
      import { useState } from 'react';

      export default function Counter() {
      const [score, setScore] = useState(0);

      function increment() {
      setScore(s => s + 1);
      }

      return (
      <>
      <button onClick={() => increment()}>+1</button>
      <button onClick={() => {
      increment();
      increment();
      increment();
      }}>+3</button>
      <h1>Score: {score}</h1>
      </>
      )
      }

更新state中的对象：

  • 状态state可以持有任何类型的JS值，包括对象，
  • 不可以直接改变React状态中持有的对象和数组，相反，想要更新一个对象和数组时，需要创建一个新的对象，或者复制现有的对象，用这个副本来更新状态。
  • 通常会使用…展开语法来复制想改变的对象和数组，下例更新一个嵌套对象
  • 推荐的做法是每次更新一个状态变量或一个相关的状态对象
    import { useState } from 'react';

    export default function Form() {
    const [person, setPerson] = useState({
    创建一个state状态
    name: 'Niki de Saint Phalle',
    artwork: {
    state状态初始量为对象
    title: 'Blue Nana',
    city: 'Hamburg',
    image: 'https://i.imgur.com/Sd1AgUOm.jpg',
    }
    });

    function handleNameChange(e) {
    setPerson({
    ...person,
    state状态的set函数，仅修改对象的姓名属性
    name: e.target.value
    });
    }

    function handleTitleChange(e) {
    setPerson({
    ...person,
    artwork: {
    同理仅修改title属性
    ...person.artwork,
    title: e.target.value
    }
    });
    }

    function handleCityChange(e) {
    setPerson({
    ...person,
    city
    artwork: {
    ...person.artwork,
    city: e.target.value
    }
    });
    }

    function handleImageChange(e) {
    setPerson({
    ...person,
    image属性
    artwork: {
    ...person.artwork,
    image: e.target.value
    }
    });
    }

    return (
    <>
    <label>
    Name:
    <input
    value={person.name}
    onChange={handleNameChange}
    />
    </label>
    <label>
    Title:
    <input
    value={person.artwork.title}
    onChange={handleTitleChange}
    />
    </label>
    <label>
    City:
    <input
    value={person.artwork.city}
    onChange={handleCityChange}
    />
    </label>
    <label>
    Image:
    <input
    value={person.artwork.image}
    onChange={handleImageChange}
    />
    </label>
    <p>
    <i>{person.artwork.title}</i>
    {' by '}
    {person.name}
    <br />
    (located in {person.artwork.city})

    alt={person.artwork.title}

更新state中的数组：

  • 数组是另一种可以存在状态state的可变JS对象，应将其视为只读状态，就像对象一样，想要更新存在的状态state中的数组时，需要创建一个新数组，或者复制现有数组，然后用新数组来更新状态
    • 数组状态state示例，内容为对象
    import { useState } from 'react';

    const initialList = [
    { id: 0, title: 'Big Bellies', seen: false },
    { id: 1, title: 'Lunar Landscape', seen: false },
    { id: 2, title: 'Terracotta Army', seen: true },
    ];

    export default function BucketList() {
    const [list, setList] = useState(
    initialList
    );

    function handleToggle(artworkId, nextSeen) {
    setList(list.map(artwork => {
    if (artwork.id === artworkId) {
    return { ...artwork, seen: nextSeen };
    } else {
    return artwork;
    }
    }));
    }

    return (
    <>
    <h1>Art Bucket List</h1>
    <h2>My list of art to see:</h2>
    <ItemList
    artworks={list}
    onToggle={handleToggle} />
    </>
    );
    }

    function ItemList({ artworks, onToggle }) {
    return (
    <ul>
    {artworks.map(artwork => (
    <li key={artwork.id}>
    <label>
    <input
    type="checkbox"
    checked={artwork.seen}
    onChange={e => {
    onToggle(
    artwork.id,
    e.target.checked
    );
    }}
    />
    {artwork.title}
    </label>
    </li>
    ))}
    </ul>
    );
    }
