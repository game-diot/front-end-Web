框架-React基础-描述UI（概述）

React是一个用于构建用户界面UI的的JS库，用户界面由按钮、文本、图形等小单元内容构建。React可以把他们组合成可以重复利用、可以嵌套的组件，从web端网站到移动端应用，屏幕上内容都可以被分解为组件。

渲染列表

  • 通常需要根据数据集合来渲染多个较为类似的组件，可以在React中使用JS的filter（）和map（）方法来实现数组的过滤和转换，将数据数组转换为组件数组
  • filter（）根据指定条件，筛选数组中的元素，返回一个包含符合条件的元素的新数组，常用于数据过滤

    const newArray = array.filter(callback(element, index, array), thisArg);
    const numbers = [1, 2, 3, 4, 5];

    // 筛选出大于 3 的数字
    const filteredNumbers = numbers.filter((num) => num > 3);

    console.log(filteredNumbers); // 输出: [4, 5]

  • map（）对数组中的每个元素执行回调函数，并将结果组成一个新数组返回，常用于数据转换、格式化

    const newArray = array.map(callback(element, index, array), thisArg);
    const numbers = [1, 2, 3, 4, 5];

    // 将每个数字乘以 2
    const doubledNumbers = numbers.map((num) => num * 2);

    console.log(doubledNumbers); // 输出: [2, 4, 6, 8, 10]

  • 组合使用filter（）和map（）
    const products = [
    { name: "Apple", price: 100, inStock: true },
    { name: "Banana", price: 50, inStock: false },
    { name: "Cherry", price: 200, inStock: true },
    ];

    // 筛选出库存商品，并提取其名称和价格
    const availableProducts = products
    .filter((product) => product.inStock) // 过滤出库存商品
    .map((product) => ({ name:
    product.name, price: product.price })); // 转换为新格式

    console.log(availableProducts);
    // 输出: [{ name: "Apple", price: 100 }, { name: "Cherry", price: 200 }]

保持组件纯粹：

  • 有些JS函数是纯粹的，纯函数，定义如下
    • 针对性，只负责一项任务，不会更改在函数调用前就已经存在的对象或变量
    • 输入输出相同，输入相同情况下，纯函数返回的结果也相同
      非纯函数组件，直接修改已经存在的变量

      let guest = 0;

      function Cup() {
      guest = guest + 1;
      return <h2>Tea cup for guest #{guest}</h2>;
      }

      export default function TeaSet() {
      return (
      <>
      <Cup />
      <Cup />
      <Cup />
      </>
      );
      }

      传递props之后，非纯函数组件，变为纯函数，而不是修改已经存在的变量（使用组件传递变量）

      function Cup({ guest }) {
      return <h2>Tea cup for guest #{guest}</h2>;
      }

      export default function TeaSet() {
      return (
      <>
      <Cup guest={1} />
      <Cup guest={2} />
      <Cup guest={3} />
      </>
      );
      }

UI树：

  • React使用树形关系建模来展示组件于模块之间的关系
  • React渲染UI树是组件之间父子关系的表示
  • 位于树顶部或者靠近根组件的组件视为顶层组件，没有子组件的组件成为叶组件，理解数据流与渲染性能

模块依赖树：

  • 用于展示JS模块之间的关系
  • 构建工具经常使用模块依赖树来捆绑客户端下载和渲染所需的JS代码，对于React应用，打包大小会导致用户体验退化
