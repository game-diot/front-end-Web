# Web 开发知识点学习来源说明

本人在 **Web 开发技术学习过程中**，持续通过多种官方与权威渠道进行系统性、结构化的知识积累。以下为当前已涉猎的重要学习资源及知识点：

## HTML 与 CSS

- **学习来源**：[W3School 中文网](https://www.w3school.com.cn/)  
  本人通过该网站系统学习了 HTML 与 CSS 的基础与进阶内容，包括但不限于页面结构布局、样式控制、响应式设计等前端核心技术。

## JavaScript 及相关进阶知识

- **学习来源**：[W3Schools 官方英文站](https://www.w3schools.com/)  
  JavaScript 的学习不仅涵盖基础语法，还深入了解了如下关键模块：
  - 异步编程（Async / Await、Promise）
  - 闭包（Closure）
  - DOM 与 BOM 操作（文档对象模型与浏览器对象模型）
  - Web API 使用
  - jQuery 库的使用与理解

## SQL 数据库基础

- **学习来源**：[W3Schools 官方英文站](https://www.w3schools.com/)  
  学习内容包括 SQL 查询语言的语法结构、增删改查操作（CRUD）、数据表关系及基本的数据管理逻辑。

## Node.js 技术栈

- **旧版本学习资料**：[Node.js 学习笔记（Poetries）](https://blog.poetries.top/node-learning-notes/)  
  涵盖早期 Node.js 模块系统、文件操作、网络服务构建等内容。

- **新版知识点来源**：[菜鸟教程 Node.js 专栏](https://www.runoob.com/nodejs/nodejs-tutorial.html)  
  学习现代 Node.js 模块化、异步 I/O、事件循环、NPM 使用、框架（如 Express）等关键内容。

## 持续学习，无限进步 ✨

技术更新日新月异，为了不断提升自身的开发能力与工程素养，**“持续学习、无限进步”** 是本人始终秉持的学习理念。当前仍在持续探索与研究的领域包括但不限于前端框架（如 React/Vue）、后端服务部署、安全机制、全栈项目实战等。

# 当前使用工具推荐

以下为本人在学习与开发过程中常用的一些高效工具，涵盖代码编辑、版本管理、项目协作、数据库操作与界面设计等多方面需求：

| 工具名称                        | 用途简述                                                                            |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| **Visual Studio Code (VSCode)** | 一款轻量级、高扩展性的代码编辑器，支持多种语言及插件系统，适合 Web 开发全流程使用。 |
| **Trae**                        | 一款接口管理工具，适用于 API 文档编写与调试（类似于 Postman），便于前后端联调。     |
| **Notion**                      | 一体化的笔记与项目管理平台，用于整理学习笔记、开发文档与时间计划。                  |
| **GitKraken**                   | 图形化 Git 客户端，提升版本控制效率，便于查看分支合并与提交记录。                   |
| **Navicat**                     | 专业的数据库管理工具，支持 MySQL、PostgreSQL 等多种数据库操作与可视化管理。         |
| **即时设计**                    | 国内高效的 UI 设计与协作平台，适合原型设计、界面协同与交互稿输出。                  |
