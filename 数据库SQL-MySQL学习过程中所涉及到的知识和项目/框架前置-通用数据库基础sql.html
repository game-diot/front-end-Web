1.SQL简介：

SQL是访问和操作数据库的标准语言

sql是什么：

  • SQL代表结构化查询语言
  • SQL可以访问和操作数据库
  • SQL国际化标准语言

    sql能做什么：

  • SQL针对数据库执行查询
  • SQL可以从数据库中检索数据
  • SQL可以在数据库中插入记录
  • SQL可以更新数据库中的记录
  • SQL可以从数据库中删除记录
  • SQL可以创建新的数据库
  • SQL可以在数据库中创建新表
  • SQL可以在数据库中创建存储过程
  • SQL可以在数据库中创建视图
  • SQL可以设置表、过程和视图的权限

sql是一个标准语言，但是不同的sql系统有不同的标准和自己专有的扩展，但是它们都以类似的方式支持sql主要命令。

  • 使用服务器端脚本语言。PHP、ASP等
  • 使用SQL获取所需数据
  • 使用HTML、CSS设置页面样式

2.SQL语法

SQL语法由易于理解的关键字组成

一个数据库通常包含多个表，每个表都有一个名称标识，并且包含带有记录的数据

SQL关键字不区分大小写，语句末尾加上分号

常见的SQL命令

  • SELECT-从数据库中提取选择数据
  • UPDATE-更新上传数据库中的数据
  • DELETE-从数据库中删除数据
  • INSERT INTO-将新数据插入数据库
  • CREATE DATABASE-创建一个新的数据库
  • ALTER DATABASE-修改数据库
  • CREATE TABLE-创建新表
  • ALTER TABLE-修改表格
  • DROP TABLE-删除表格
  • CREATE INDEX-创建索引，即搜索关键字
  • DROP INDEX-删除索引

3.SQL SELECT语句：

SELECT语句用于从数据库中选择数据

语法：在指定表中选择指定数据

SELECT column1，column2，….

FROM tableName

选择所有列：星号*

SELECT * FROM tableName

例子：客户表中选择客户名、城市

SELECT customerName，city

FROM customers；

4.SQL SELECT DISTINCT语句：

SELECT DISTINCT语句用于仅返回不同的值

在表中一列常包含许多重复的值，此方法可以列出不同的值

语法：

SELECT DSITINCT column1，…

FROM tableName；

例子：选择客户表中不同的国家

SELECT DISTINCT country

FROM customers；

结合计数函数COUNT（），可以返回不同国家的数量：

SELECT COUNT(DISTINCT country)

FROM customers；

5.SQL WHERE语句；

WHERE用于过滤记录，可以仅提取出满足指定条件的记录

语法：不仅用于SELECT，也可以在UPDATE、DELETE等语句中

SELECT column1，…

FROM tableName

WHERE condition；条件

文本字段与数字字段：

SQL要求文本值周围要有引号，但是数字字段不应使用引号

SELECT * FROM customers

WHERE customerID=1；

WHERE字句中的运算符：

可以使用除了运算符之外的运算符来过滤搜索，

=、>、<、≥、≤、! =、BETWEEN、LIKE、IN等

SELECT * FROM customers

WHERE customerID > 80；

6.SQL ORDER BY 语句：

ORDER BY可以按升序或降序对选择结果进行排序

语法：DESC降序、ASC升序（默认），字符串按照字母顺序排序，选择多列排序，列1相同排列2。可以同时使用升序降序

SELECT column，…

FROM tableName

ORDER BY column1，columne2，… ASC | DESC;

ORDER BY Country ASC, CustomerName DESC;（列1升序相同，列2降序排）

7.SQL 逻辑运算符：

WHERE字句可以包含多个AND运算符，可以同时多个条件筛选记录

AND：并列筛选条件

语法：记录符合所有条件，则返回，符合全部条件才成功

SELECT column，…

FROM tableName

WHERE condition1 AND condition2 AND ….；

OR：或，筛选条件

语法：记录符合一条件，就会返回，至少符合一个条件才成功

SELECT column，…

FROM tableName

WHERE condition1 OR condition2 OR…;

NOT：非，反向筛选记录

语法：与筛选条件相反，才返回，都不符合条件才成功

SELECT column，…

FROM tableName

WHERE NOT condition2，…；与！=类似

三者混合使用：

SELECT * FROM customers

WHERE (id >50 AND id <70) OR name = BOB NOT years < 18;

8.SQL INSERT INTO语句：

INSERT INTO用于在表中插入新记录

语法1：指定要插入的列名和值

INSERT INTO tableName ( column1，column2，….)

VALUES (value1，value2，…)

语法2：为所有列添加至，无需指定列名，要保证值的顺序与表中列的顺序一致

INSERT INTO tableName

VALUES (value1，value2，…)

INSERT INTO Customers (CustomerName, ContactName, Address, City, PostalCode, Country)

INSERT INTO Customers (CustomerName, City, Country)

例子：插入多行数据，逗号分隔每组值

INSERT INTO Customers (CustomerName, ContactName, Address, City, PostalCode, Country)

9.SQL NULL值：

具有NULL值的字段是没有值的字段

表中的某个字段可选，可以使用插入新记录或者更新记录而不是像该字段中添加值，然后这个字段将以NULL值保存

NULL值不同于零值或包含空格的字段，NULL值的字段是在创建记录时留空的字段（用新的纪录、或者更新记录）

测试NULL值：

无法使用比较运算符来验证测试NULL值，需要使用以下方法

  • IS NULL用于测试空值NULL（始终使用IS NULL来查找空值）

    SELECT columns FROM tableName

    WHERE columns IS NULL;会返回指定列为空的记录

  • IS NOT NULL用于测试非空值NOT NULL

    SELECT columns FROM tableName

    WHERE columns IS NOT NULL;

10.SQL UPDATE语句：

UPDATE语句可以修改表中现有的记录

如果省略WHERE筛选语句，则所有的记录都将被更新

语法：注意WHERE中的字句UPDATE，WHERE字句应该制定更新那些记录，省略WHERE会更新表中的所有记录

UPDATE tableName

SET column1 = value1，value2，…

WHERE condition；

例子：更新表中的记录

UPDATE customers

SET contactName = “Tom”，city=“China”

WHERE customerID = 1；

例子：更新表中多条记录，WHERE字句决定了更新多少条记录

UPDATE customers

SET contactName=“JACK”

WHERE country = “Mexico”；

11.SQL DELETE语句：

DELETE语句用于删除表中现有的纪录

语法：注意WHERE字句筛选内容

DELETE FROM tableName WHERE condition；

例子：删除客户表中的某个客户

DELETE FROM cunstomers WHERE customerName = “name”

例子：删除所有记录，不删除表，意味着表结构、属性、索引不变

DELETE FROM tableName；

例子：删除表，使用DROP TABLE语句

DROP TALBE tableName；

12.SQL TOP、LIMIT、FENTCH FIRST或ROWNUM字句：

  • SELECT TOP:：用于指定返回数目的记录
    • 仅返回客户表的前三条记录（不同的数据库系统操作方法不同）
      • SELECT TOP 3 * FROM customers（SQL）
      • SELECT * FROM customers LIMIT 3;（MySQL）
      • SELECT * FROM customers FENTCH FIRST 3 ROWS ONLY；（Oracle）
    • 返回客户表的前50%记录
      • SELECT TOP 50 PERCENT * FROM customers；（SQL）
      • SELECT * FROM customers FENCH FIRST 50 PERCENT ROWS ONLY；（Oracle）
  • TOP 与 WHERE：用于指定返回数目并符合条件的记录
    • 返回客户表前三条，条件为国家德国的记录
      • SELECT TOP 3 * FROM customers WHERE country = “germany”；（SQL）
      • SELECT * FROM customers WHERE country=“germany” LIMIT 3；（MySQL）
      • SELECT * FROM customers WHERE country=“germany” FENTCH FIRST 3 ROWS ONLY；（Oracle）
  • TOP 与 ORDER BY：堆筛选的结果进行排序，并按照排序结果返回指定数目记录
    • 按照customerName字母反向排序，并返回前三条记录
      • SELET TOP 3 * FROM customers ORDER BY customerName DESC；（SQL）
      • SELECT * FROM customers ORDER BY customerName DESC LIMIT 3 ；（MySQL）
      • SELECT * FROM customers ORDER BY customerName DESC FETCH FIRST 3 ROWS ONLY；（Oracle）

12.SQL聚合函数：

聚合函数是对一组值执行计算并返回单个值的函数，聚合函数通常与语句SELECT 、 GROUP BY的子句一起使用

GROUP BY字句将结果分成几组值，聚合函数可为每个组返回计算结果

常用的SQL聚合函数：聚合函数会忽略空值NULL，除了COUNT（）

  • MIN（）-返回选定列中的最小值
  • MAX（）-返回选定列中的最大值
  • COUNT（）-返回集合中的行数
  • SUM（）-返回数值列的总和
  • AVG（）-返回数值列的平均值

13.聚合函数详解：

  • MIN（）-返回选定列中的最小值
    • 语法：

      SELECT MIN(column) FROM tableName

      WHERE condition

    • 设置别名：
      • 使用MIN()和MAX()时，返回的列将没有描述性名称，仅包含值，可以为列指定名称，使用AS关键字
        • SELECT MIN (PRICE_columns) AS smalllestPrice
        • FROM tableName；
  • MAX（）-返回选定列中的最大值
    • 语法

      SELECT MAX（column） FROM tableName

      WHERE condition；

    • 与GROUP BY 结合使用，可以返回表中的每个类别的最小价格
      • SELECT MIN(PRICE) AS smallestPrie，CategoryID
      • FROM Products
      • GROUP BY categoryID；
  • COUNT（）-返回集合中的行数
    • 语法：

      SELECT COUNT(columns) FROM tableName

      WHERE condition

    • 查找表中的总行数，包括NULL值所在的那一条记录
      • SELECT COUNT(*) FROM Products；
    • 查找不为空的行数，只需指定列名即可
      • SELECT COUNT(productName) FROM products；
    • COUNT与WHERE结合使用，来计算指定条件的数量
      • SELECT COUNT (productID) FROM products
      • WHERE price >20；
    • 忽略重复项，使用DISTINCT关键字，具有相同值的一行被视为一行
      • SELECT COUNT (DISTINCT price) FROM products；
    • 使用别名 AS关键字，别名为记录数中括号括起【】
      • SELECT COUNT (*) AS [Number of records] FROM products；
    • COUNT 与GROUP BY 结合使用,返回products表中每个类别的记录数
      • SELECT COUNT(*) AS [Number of records]，CategoryID
      • FROM produts
      • GROUP BY CategoryID;
  • SUM（）-返回数值列的总和
    • 语法
      • SELECT SUM(columns) FROM tableName
      • WHERE condition；
    • 返回表中Quantity所有字段的总和
      • SELECT SUM(Quantity) FROM table
    • 与WHERE字句，筛选条件
      • SELECT SUM(Quantitu) FROM table
      • WHERE productID=11
    • 使用别名AS
      • SELECT SUM(Quantity) AS total FROM table；
    • 与GROUP BY结合使用，返回该表中Quantity的每个值，这里的求和指相同id的不同quantity之和
      • SELECT OrderID，SUM(Quantity) AS 【total quantity】
      • FROM OrderDetails
      • GROUP BY OrrderID;
    • 带有表达式的SUM()，假设每件产品为10元，找到该产品单位的总收入
      • SELECT SUM(Quantity * 10)
      • FROM OrderDetails；
    • 也可以找到另一个表内的实际价格来求总收入
      • SELECT SUM（Price * Quantity）
      • FROM OrderDetails
      • LEFT JOIN Products ON OrderDetails.ProductID = Products.ProductID；
  • AVG（）-返回数值列的平均值
    • 语法：注意NULL值会被忽略
      • SELECT AVG(column) FROM table
      • WHERE condition；
    • 查找所有产品的平均价格
      • SELECT AVG(price) FROM Products；
    • 添加WHERE字句来定筛选条件，返回类别1中产品的平均价格
      • SELECT AVG(Price) FROM Products
      • WHERE CategoryID = 1；
    • 使用别名AS
      • SELECT AVG(Price) AS [average price] FROM Products；
    • 高于平均水平，返回所有价格高于平均价格的产品
      • SELECT * FROM Products
      • WHERE price >（SELECT AVG(price) FROM Products）；
    • AVG与GROUP BY结合，返回产品表中每个类别的平均价格
      • SELECT AVG(price) AS AveragePrice，CategoryID
      • FROM Products
      • GROUP BY CategoryID;

14.SQL LIKE运算符：

LIKE运算符用于在WHERE子句，可在列中搜索指定的模式

有两个通配符常与LIKE运算符一起使用

  • %百分号，代表0个、1个、多个字符
  • _下划线，代表1个字符

    语法：

    SELECT column，…

    FROM table

    WHERE columnN LIKE pattern

    例子：选择所有字母a开头的用户

    SELECT * FROM Customers

    WHERE CustomerName LIKE ‘a%’

    • _下划线通配符，代表单个字符，可以是任意字符，用于搜索
      • 返回以L开头的城市的客户

        SELECT * FROM Customers

        WHERE city LIKE 'L_nd__';

    • %百分号通配符，代表任意数量的字符
      • 返回包含字母L的城市的客户

        SELECT * FROM Customers

        WHERE city LIKE ‘%L%’；

    通配符组合，几个选择几个LIKE

    • 以L开头的记录 “L%”
    • 以a开头或b开头 ，可以使用逻辑运算符 AND OR
      • WHERE CustomerName LIKE “a%” OR CustomerName LIKE “b%”
    • 以L结尾的记录 “%L”
    • 以a开头，b结尾 “a%b”
    • 包含a的记录 “%a%”
    • 以a开头且长度至少为三个的字符“a__%”

    不使用通配符，需要字符完全匹配才可以返回结果

其他通配符：

  • %百分号：可以代替任意数量的字符
  • _下划线：可以代表单个字符
  • []中括号：如果与【】通配符中的任何字符匹配，则返回结果，下例是选择bsp任意开头的记录
    • SELECT * FROM Customers
    • WHERE CustomerName LIKE “[bsp]%”
  • -减号：指定通配符内的字符范围，下例是选择以a、b、c、d开头的客户
    • SELECT * FROM Customers
    • WHERE CustomerName LIKE “[a-d]%”
  • 组合使用通配符
  • 不使用通配符

15.SQL IN运算符

IN运算符允许在WHERE子句中指定多个值，是多重条件的OR的缩写

  • 语法：
    • SELECT columns FROM table
    • WHERE column IN (value1，value2，…)
  • 例子：返回来自“德、法、英”的所有客户
    • SELECT * FROM Customers
    • WHERE Country IN (”德”，…)
  • 与NOT使用，可以否定条件，返回所有不属于列表中任何值得记录
    • 返回所有不来自德、法、英的客户
    • SELECT * FROM Customers
    • WHERE Country NOT IN (”德”，…)
  • IN 在WHERE的子句中使用子查询，返回查询中存在于子查询的记录
    • 返回订单表中有订单的客户
    • SELECT * FROM Customers
    • WHERE CustomerID IN (SELECT CustomerID FROM Orders)；
  • NOT IN检查IN的结果是否正确
    • 返回订单表中未下单的客户
    • SELECT * FROM Customers
    • WHERE CustomerID NOT IN (SELECT CustomerID FROM Orders)；

16.SQL BETWEEN运算符：

BETWEEN运算符可以选择给定范围内的值，可以是数字、文本、日期

使用BETWEEN运算符，需要包括开始值与结束值

  • 语法：
    • SELECT column FROM table
    • WHERE column BETWEEN value1 AND value2
  • 介于：选择价格10-20之间的商品
    • SELECT * FROM Products
    • WHERE Price BETWEEN 10 AND 20；
  • 不介于：NOT BETWEEN 不在10-20之间
    • SELECT * FROM Product
    • WHERE Pirce NOT BETWEEN 10 AND 20;
  • BETWEEN与IN结合双重筛选,选择价格10-20而且id为1，2，3
    • SELECT * FROM Products
    • WHERE Price BETWEEN 10 AND 20
    • AND CategoryID IN (1,2,3)
  • BETWEEN文本值：按字母顺序排序选择ProductName在bob和tom之间的所有产品
    • SELECT * FROM Products
    • WHERE ProductName BETWEEN ‘Bob’ AND ’Tom’
    • ORDER BY ProductName
  • NOT BETWEEN的文本值
  • 日期之间：选择1996.7.1和1996.7.31之间的所有订单
    • SELECT * FROM Orders
    • WHERE OrderDate BETWEEN #07/01/1996# AND #07/31/1996#；
  • 日期之间选择另一种形式
    • SELECT * FROM Orders
    • WHERE OrderDate BETWEEN ‘1996-07-01’ AND ‘1996-07-31’；

17.SQL别名AS：

别名AS为表或表中的列赋予临时名称，别名通常更具有可读性，

别名仅在该查询持续期间存在

  • 例子：为所选列赋予别名
    • SELECT CustomerID AS ID
    • FROM Customers
  • AS是可选的，可以跳过关键字，获取相同的结果
    • SELECT CustomerID ID
    • FROM Customers;
  • 语法：所选的列与表的别名
    • 所选列，多个由逗号隔开
      • SELECT columns AS easeName，columns1 AS easeName1…
      • FROM table
    • 所选表
      • SELECT columns
      • FROM table AS easeName
  • 带有空格字符的别名：使用方括号或者双引号来括起别名
    • SELECT ProductName AS [My Great Products] FROM Products;
    • SELECT ProductName AS “My Great Products” FROM Products；
  • 连接多列：创建一个Address别名，该别名组合了3列内容（使用逗号或者空格，是为了区分不同列之间的内容）
    • SELECT CustomerName，name1+‘，’+name2 + ‘，’+name3 AS Address FROM Customers；（SQL）
    • SELECT CustomerName，CONCAT(name1，‘，’，name2，‘，’，name3) FROM Customers；（MySQL）
    • SELECT CustomerName，（name1 ||‘，’||name2||‘ ’||name3）AS Address FROM Customers；（Oracle）
  • 表格别名，适用于同样的规则（很少使用表别名）

  • 别名在以下情况很有用
    • 查询涉及多个表，表别名
    • 查询中使用函数
    • 列名太大或不太易读
    • 两列或多列组合在一起

18.SQL链接：

使用JOIN字句可以根据两个或者多个表之间相关的列来合并他们的行

在SQL语句中多个表操作，指定列的时候，包含表名很好：table.columnname

  • 例子：选择两个表中具有匹配值的记录
    • SELECT Orders.OrderID, Customers.CustomerName, Orders.OrderDate
    • FROM Orders
    • INNER JOIN Customers ON Orders.CustomerID=Customers.CustomerID;（两个表共同的列来合并）
  • 根据不同的数据需要使用不同的连接方式a、b、c 表左右以及共同部分
    • INNER JOIN：返回两个表中具有匹配值的记录，b
      • 语法：

        SELECT column_name(s) FROM table1

        INNER JOIN table2 ON table1.column_name = table2.column_name

        ;

      • 例子：连接三张表，

      SELECT Orders.OrderID, Customers.CustomerName, Shippers.ShipperName FROM ((Orders

      INNER JOIN Customers ON Orders.CustomerID = Customers.CustomerID)

      INNER JOIN Shippers ON Orders.ShipperID = Shippers.ShipperID);

    • LEFT JOIN：返回左表中的所有记录，以及右表中有匹配的记录，a+b
      • 例子：

      SELECT Customers.CustomerName, Orders.OrderID

      FROM Customers

      LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID

      ORDER BY Customers.CustomerName;

    • RIGHT JOIN：返回右表中的所有记录，以及左表中有匹配的记录，b+c
      • 例子：

      SELECT Orders.OrderID, Employees.LastName, Employees.FirstName

      FROM Orders

      RIGHT JOIN Employees ON Orders.EmployeeID = Employees.EmployeeID

      ORDER BY Orders.OrderID;

    • FULL JOIN：当左表和右表有匹配项时，返回所有记录a+b+c
      • 例子：

      SELECT Customers.CustomerName, Orders.OrderID

      FROM Customers

      FULL OUTER JOIN Orders ON Customers.CustomerID=Orders.CustomerID

      ORDER BY Customers.CustomerName;

19.SQL UNION运算符 联盟：

UNION运算符用于组合两个或者多个SELECT语句的结果集，注意如下

  • UNION组合的每个SELECT语句必须具有相同数量的列
  • 这些列必须具有相似的数据类型
  • 每个SELECT语句中的列必须按照相同的顺序
    • 语法：UNION默认仅选择不同的值，如果需要重复值存在使用UNION ALL，集合结果的列，通常与第一个SELECT语句中的列相同

    （两列没关系，只要类型相同就可以合并，合并后以第一列名为准）

    • SELECT column1 FROM table1
    • UNION
    • SELECT column2 FROM table2；

    • UNION与WHERE：会返回符合筛选结果的两列，合并为一列

      SELECT City, Country FROM Customers

      WHERE Country='Germany'

      UNION

      SELECT City, Country FROM Suppliers

      WHERE Country='Germany'

      ORDER BY City;

    • UNION ALL 与WHERE：允许重复值存在，将符合条件的列合并一起

      SELECT City, Country FROM Customers

      WHERE Country='Germany'

      UNION ALL

      SELECT City, Country FROM Suppliers

      WHERE Country='Germany'

      ORDER BY City;

20.SQL GROUP BY语句：

将具有相同值的行分组为汇总行，常与聚合函数一起使用

  • 语法：理解为选择的几列，按固定列不动分组，不固定列合并相加记和
    • SELECT column FROM table
    • WHERE condition
    • GROUP BY column
    • ORDER BY column；
  • 例子：列出每个国家的客户数量，从高到低排序
    • SELECT COUNT（CustomerID），Country FROM Customers
    • GROUP BY Country
    • ORDER BY COUNT（CustomerID） DESC；

21.SQL HAVING子句：

该关键字可以和聚合函数一起使用，通常与GROUP BY 一起使用，与WHERE字句类似，但是WHERE字句用于过滤行的记录，HAVING用于过滤分组后的结果

理解为，WHERE是过程中的过滤筛选，HAVING结果的过滤筛选

  • 语法：
    • SELECT column FROM table
    • WHERE condition
    • GROUP BY column
    • HAVING condition
    • ORDER BY column；
  • 例子：列出每个国家的客户数量，仅包括客户超过5人的国家
  • 这里的COUNT(CustomerID)仅仅是一个数字而已
    • SELECT COUNT (CustomerID)，Country FROM Customers
    • GROUP BY Country
    • HAVING COUNT (CustomerID) > 5;

22.SQL EXISTS运算符：

EXISTS运算符用于测试子查询中是否存在任何记录，存在返回TRUE

  • 语法：
    • SELECT column FROM table
    • WHERE EXISTS
    • （SELECT column FROM table WHERE condition）；
  • 例子：返回TRUE，并列出产品价格低于20的供应商
    • SELECT SupplierName FROM Suppliers
    • WHERE EXISTS (SELECT ProductName FROM Products WHERE Products.SupplierID = Suppliers.supplierID AND Price <20)；
  • 例子：返回TRUE，列出产品价格等于22的供应商
    • SELECT SupplierName FROM Suppliers
    • WHERE EXISTS
    • (SELECT ProductName FROM Products
    • WHERE Products.Suppliers.supplierID AND Price = 22)；

23.SQL ANY AND ALL运算符：

ANY和ALL运算符允许对单个列值和一系列其他值进行比较，理解为条件判断ALL和ANY的运算结果是每个值为TRUE FALSE，只选择TRUE的值作为判断

  • ANY：结果返回布尔值、任何子查询值满足条件就返回TRUE，意味着范围内存在满足值就返回TRUE
    • 语法：运算符为标准运算符> < ≥ ≤ ! = <> =
      • SELECT columns FROM table
      • WHERE column operator ANY (
      • SELECT column FROM table WHERE condition)；
  • ALL：结果返回布尔值、所有子查询值满足条件则返回TRUE，常与SELECT、WHERE、HAVING语句一起使用，意味着范围全满足要求才返回TRUE
    • 语法：
      • SELECT的ALL语法：operator为标准运算符
        • SELECT ALL column FROM table
        • WHERE condition；
      • WHERE或HAVING的ALL语法：
        • SELECT column FROM table
        • WHERE column operator ALL（
        • SELECT column FROM table
        • WHERE condition）；
  • ANY示例：找出OrderDetails表中数量为10的记录，就列出ProductName（Quantity列中存在等于10的就返回TRUE）
    • SELECT ProductName FROM Products
    • WHERE ProductID = ANY（
    • SELECT ProductID FROM OrderDetails
    • WHERE Quantity = 10）；
  • ALL示例：列出所有产品名
    • SELECT ALL ProductName FROM Products
    • WHERE TRUE；
  • ALL示例：如果OrderDetails表中所有记录数量都等于10，则列出ProductName，结果会返回FALSE，因为Quantity列中不全等于10
    • SELECT ProductName FROM Products
    • WHERE ProductID = ALL（
    • SELECT ProductID FROM OrderDetails
    • WHERE Quantity = 10）；

24.SQL SELECT INTO语句：

SELECT INTO语句用于将数据从一个表中复制到一个新表里

  • SELECT INTO语法：新表中使用就表中定义的列名和类型来创建，也可以使用AS字句来创建新的列名
    • 将所有列复制到新表中：
      • SELECT * INTO newtable 【IN externaldb】
      • FROM oldtable
      • WHERE condition；
    • 仅复制旧表中部分列到新表：
      • SELECT column1，column2，…
      • INTO newtable 【IN externaldb】
      • FROM oldtable
      • WHERE condition；
  • 示例：
    • 创建客户的备份副本：
      • SELECT * INTO CustomersBackup2025 FROM Customers；
    • 使用IN字句将一个表复制到另一个数据库的新表中
      • SELECT * INTO CustomersBackup2025 IN ‘Backup.mdb’
      • FROM Customers；
    • 将两列复制到新表中

25.SQL INSERT INTO SELECT语句：

INSERT INTO SELECT语句从一个表复制数据并插入到另一个表中，要求原表和目标表中的数据类型匹配，目标表的现有记录不会受影响，在下面加上记录

  • INSERT INTO SELECT语法:
    • 将所有列从一个表1复制到另一个表2

    • 将一个表中的某列复制到另一个表中

      • FROM table1
      • WHERE condition；
  • 示例：为填充数据的列将包含NULL
    • 将供应商列复制到客户列，
      • INSERT INTO Customers（CustomerName，City，Country）

    • 将供应商复制到客户列，若复制全部列，则可以省却括号及其内容，前提是表之间列的顺序一致
      • INSERT INTO Customers（CustomerName, ContactName, Address, City, PostalCode, Country）

    • 仅将德国供应商复制到客户列中

26.CASE表达式：

CASE表达式会检查条件，并在第一个条件满足时返回一个值，类似于JS的switch，一旦条件为真，就会停止读取并返回结果，如果没有条件为真，则会返回子句中ELSE的值，

没有条件为真，没有设置ELSE部分则返回NULL

  • CASE语法：
    • CASE
      • WHEN condition1 THEN result1
      • WHEN condition2 THEN result2
      • ….
      • ELSE result
    • END；
  • 示例：
    • 检查条件，满足的第一个条件时返回对应的结果
      • SELECT OrderID，Quantity，
      • CASE
        • WHEN Quantity>30 THEN ‘The Quantity is greater than 30’
        • WHEN Quantity=30 THEN’The quantity is 30’
        • ELSE ‘The quantity is under 30’
      • END AS QuantityText
      • FROM OrderDetails;
    • 按照City对客户进行排序，但是如果City为NULL就按照Country排序
      • SELECT CustomerName，City，Country
      • FROM Customers
      • ORDER BY (
      • CASE
        • WHEN City IS NULL THEN Country
        • ELSE City
      • END)；

27.SQL NULL函数：

常用判断NULL函数如下IFNULL和ISNULL，COALESCE（）通用函数，NVL为Oracle专用函数

  • IFNULL()：如果表达式为NULL，允许返回一个指定的值
    • 示例：如果UnitsOnOrder为NULL，则将其替换为0（MySQL）
      • SELECT ProductName，UnitPrice * （UnitsInStock+IFNULL(UnitsOnOrder，0)）
      • FROM Products；
    • COALESCE（）函数可以达到同样效果
      • SELECT ProductName，UnitPrice*（UnitsInStock+COALESCE（UnitsOnOrder，0））
      • FROM Products；
  • ISNULL()：当表达式为NULL，允许返回一个指定的值
    • 示例：UnitsOnOrder为NULL，将其替换为0（SQL）
      • SELECT ProductName，UnitPrice*（UnitsInStock+ISNULL(UnitsOnOrder，0)）
      • FROM Products；
    • COALESCE（）函数可以达到同样效果
      • SELECT ProductName，UnitPrice*（UnitsInItock+COALESCE(UnitsOnOrder，0)）
      • FROM Products；
    • 示例：表达式为NULL，则MS Access函数返回TRUE -1,FALSE 0（微软Access）
      • SELECT ProductName，UnitPrice*（UnitsInStock+IIF(IsNULL(UnitsOnOrder)，0，UnitsOnOrder)）
      • FROM Products；
  • VAL（）同上示例实现相同效果（Oracle）
    • SELECT ProductName，UnitPrice*（UnitsInStock+NVL(UnitsOnOrder，0)）
    • FROM Products；
  • COALESCE（）函数也可以同样替代
    • SELECT ProductName，UnitPrice*（UnitsInStock+IIF(IsNULL(UnitsOnOrder)，0，UnitsOnOrder)）
    • FROM Products；

28.SQL Server的SQL存储程序，数据库服务：

存储程序时可以保存准备好的SQL代码，可以反复使用

如果有一个反复编写的SQL查询，可以保存为存储程序，然后调用即可执行

也可以将参数传递给存储程序，便于存储程序可以根据传递的不同参数采取不同行动

  • 存储程序语法：
    • CREATE PROCEDURE procedureName
    • AS sql_statement
    • GO；
  • 执行存储程序：
    • EXEC procedureName；
  • 例子：选择表中的所有记录
    • 存储程序代码：
      • CREATE PROCEDURE SelectALLCustomers
      • AS
      • SELECT * FROM Customers
      • GO；
    • 执行存储程序：
      • EXEC SelectALLCustomers；
  • 具有一个参数的存储程序：用于从客户表中选择来自特定城市的客户
    • 存储程序代码：
      • CREATE PROCEDURE SelectALLCustomers @city nvarchar（30）
      • AS
      • SELECT * FROM Customers WHERE City = @City
      • GO；
    • 执行存储程序：
      • EXEC SelectALLCustomers @City=‘London’；
  • 具有多个参数的存储程序：用于从客户表中具有特定邮政编码的特定城市的客户,(需要列出每个参数和数据类型并使用逗号分隔)
    • 存储程序代码：
      • CREATE PROCEDURE SelectALLCustomers @City nvarchar（30），@PostalCode nvarchar（10）
      • AS
      • SELECT * FROM Customers WHERE City = @City AND PostalCode = @PostalCode
      • GO；
    • 执行存储程序
      • EXEC SelectALLCustomers @City=‘London’，@PostalCode=‘WA1 1DP’

7.约束：

SQL约束用于指定表中数据的规则

约束可以在CREAT TABLE创建表时指定，也可以在创建表之后ALTER TABLE指定

  • 语法：
    • CREATE TABLE tablename（
    • column1 datatype constraint，
    • column2 datatype constraint，…）；

约束用于限制可进入表的数据类型，可以确保表中的数据的准确性和可靠性，如果约束与数据操作之间存在任何冲突，则操作将终止，

约束可以是列约束，也可以是表约束，常用的约束如下

  • NOT NULL：确保列中不能有NULL值
  • UNIQUE：确保列中没有重复值
  • PRIMARY KEY NOT NULL：和UNIQUE组合，唯一的标识表中的每一行
  • FOREIGN KEY：防止破坏表格之间连接的操作
  • CHECK：确保列中的值满足特定条件
  • DEFAULT：如果未指定值，则为列设置默认值
  • CREATE INDEX：用于快速创建和检索数据库中的数据

8.NOT NULL约束：

默认情况下，数据列中可以保存NULL，NOT NULL可以约束强制列不接受NULL，这会强制一个字段始终包含一个值，如果不想该字段添加值，就无法插入新记录或更新记录

  • 创建表时使用NOT NULL约束
    • 例如在创建Persons表，ID、Name列不会接受NULL值
      • CREAT TABLE Persons （
      • ID int NOT NULL,
      • Name varchar（255） NOT NULL）;
  • 创建表后对列使用NOT NULL列约束
    • NOT NULL在persons表已创建的情况下对Age列创建约束
      • SQL/MS Access
        • ALTER TABLE Persons
        • ALTER COLUMN Age int NOT NULL；
      • MySQL
        • ALTER TABLE Person
        • MODIFY COLUMN Age int NOT NULL;
      • Oracle
        • ALTER TABLE Person
        • MODIFY Age int NOT NULL;

9.UNIQUE约束：

UNIQUE约束确保列中的所有值都不同，UNIQUE和PRIMARY KEY约束都为一列或几列提供了唯一性的保证，PRIMARY KEY约束包含UNIQUE约束

每个表可以有多个UNIQUE约束，只能有一个PRIMARY KEY约束

  • 创建表时的UNIQUE约束：
    • SQL/Oracle/MS Access
      • CREATE TABLE Persons（
      • ID int NOT NULL UNIQUE,
      • Name varchar（255） NOT NULL）;
    • MySQL:
      • CREATE TABLE Persons（
      • ID int NOT NULL,
      • Name varchar（255） NOT NULL,
      • UNIQUE(ID,Name)
      • ）；
    • 对多个列实施UNIQUE约束（MySQL/SQL/Oracle/MS Access）
      • CREATE TABLE Persons（
      • IN int NOT NULL,
      • Name varchar（255）NOT NULL,
      • CONSTRAINT UC_Person UNIQUE (ID,Name)
      • ）；
  • 创建表后，选择列使用UNIQUE约束：
    • 单个列创建约束
      • ALTER TABLE Persons
      • ADD UNIQUE (ID)；
    • 多个列创建约束
      • ALTER TABLE Persons
      • ADD CONSTRAINT UN_Person UNIQUE (ID,Name)；
    • 删除UNIQUE约束：如果没有命名约束，系统会自动生成，使用查询名称之后，在指定删除约束
      • MySQL：
        • ALTER TABLE Persons
        • DROP INDEX UC_Person；
      • SQL/Oracle/MS Access
        • ALTER TABLE Persons
        • DROP CONSTRAINT UC_Person；

10.PRIMARY KEY 主键约束：

PRIMARY KEY主键约束唯一标注标识表中的每个记录，（为每一行标注命名？）

主键约束的作用：
  1. 确保表中每一行数据的唯一性。即主键列的值唯一不重复
  1. 提供数据完整性，避免重复和冗余数据。即主键列的值完整不为空
  1. 作为外键的参照，实现表与表之间的关系。即主键被引用为外键
  1. 提高基于主键列的查询效率。即主键会自动创建索引
  1. 便于数据恢复和维护。

主键必须包含UNIQUE值，而且不能包含NULL

一个表只能有一个主键，而且在表中，这个主键可以有单个列、多个列组成

  • 在创建表时创建主键PRIMARY KEY，以Person表的ID列为主键
    • MySQL
      • CREATE TABLE Persons（
      • ID int NOT NULL,
      • Name varchar（255） NOT NULL,
      • PRIMARY KEY(ID)
      • ）;
    • SQL/Oracle/MS Access
      • CREATE TABLE Persons（
      • ID int NOT NULL PRIMARY KEY,
      • Name varchar（255）NOT NULL
      • ）；
  • 为多个列定义PRIMARY KEY约束，只有一个主键，主键有两列值
    • MySQL/SQL/Oracle/MS Access
      • CREATE TABLE Persons（
      • ID int NOT NULL,
      • Name varchar（255）NOT NULL,
      • CONSTRAINT PK_Person PRIMARY KEY(ID,Name)
      • ）；
  • 创建表后创建主键PRIMARY KEY,注意朱建忠不包含NULL值
    • 对ID单个列创建主键约束：
      • MySQL/SQL/Oracle/MS Access
        • ALTER TABLE Persons
        • ADD PRIMARY KEY (ID);
    • 对多个列创建主键约束
      • MySQL/SQL/Oracle/MS Access：
      • ALTER TABLE Persons
      • ADD CONSTRAINT PK_Person PRIMARY KEY(ID,Name)；
  • 删除PRIMARY KEY 约束
    • MySQL
      • ALTER TABLE Persons
      • DROP PRIMARY KEY
    • SQL/Oracle/MS Access
      • ALTER TABLE Persons
      • DROP CONSTRINT PK_Person；

11.FOREIGN KEY外键约束：

外键约束用于防止破坏表之间连接的操作，

外键是一个表中的一个字段，或者字段合集，他引用另一个表中的主键。

具有外键的表称为子表，具有主键的表称为引用表或者父表

外键约束可以防止无效数据插入外键存在的列，有效数据为附表中包含的值

  • 创建表时的FOREIGN KEY 外键：
    • MySQL：创建Orders表，并使PersonID列为外键列
      • CREATE TABLE Orders（
      • OrderID int NOT NULL,
      • PersonID int，
      • PRIMARY KEY (OrderID),
      • FOREIGN KEY (PersonID) REFERENCES Persons（PersonID）

14.CREATE INDEX创建索引语句：

CREATE INDEX语句用于在表中创建索引，便于更快的检索数据。

  • CREATE INDEX语法：不同的数据库语法不同，注意查看

    • 在表上创建为一索引，不允许重复值UNIQUE

      • ON Persons（Name，Age）；
  • 删除索引
    • SQL
      • DROP INDEX indexname ON tablename；
    • MySQL
      • ALTER TABLE tablename
      • DROP INDEX indexname；

17.SQL视图：

视图是一个基于SQL语句结果集的虚拟表，包含行与列，视图中的字段是数据库中真实表的字段，

可以向视图中添加SQL语句和函数并呈现数据，就像数据来自单个表一样

  • 创建视图CREATE VIEW
    • 语法：视图始终显示最新数据，每次用户查询时，数据库会重新创建视图
      • CREATE VIEW viewname AS
      • SELECT column1，column2，…
      • FROM tablename
      • WHERE condition；
    • 例子：创建一个视图，选择产品表中价格高于平均价格的产品
      • CREATE VIEW [Products Above Average Price] AS
      • SELECT ProductName，Price
      • FROM Products
      • WHERE Price >(SELECT AVG(Price) FROM Products);
    • 创建完后，查询视图
      • SELECT * FROM 【Products Above Average Price】；
  • 更新视图CREATE OR REPLACE VIEW
    • 语法：
      • CREATE OR REPLACE VIEW viewname AS
      • SELECT column1，column2，…
      • FROM tablename
      • WHERE condition；
    • 例子：将城市列添加到中国客户视图中
      • CREATE OR REPLACE VIEW [China Customers] AS
      • SELECT CustomerName，City
      • FROM Customers
      • WHERE Country=‘’China；
  • 删除视图
    • 语法
      • DROP VIEW viewname
    • 例子，删除中国客户视图
      • DROP VIEW 【China Customers】；

18.SQL注入

用户通过输入数据库的数据，数据中包含代码，这样会对数据库进行恶意操作

SQL注入值通过网页输入将恶意代码放置在SQL语句中

  • 网页中的SQL：注入通常发生在要求用户输入时，用户没有提供内容，而是向网页提供了一条SQL，服务器就会在不知情的情况下运行数据库语句
    • 例子通过SELECT添加txtUserId变量创建语句，从用户输入中获取
      • txtUserId = getRequestString（‘UserId’）；
      • txtSQL = “SELECT * FROM Users WHERE UserId =” + txtUserID；
  • 注入的可能风险
    • 基于”1=1“的注入始终成立
    • 基于“=”的注入始终成立
    • 基于批量处理SQL语句的注入
  • 保护免受注入

    使用SQL参数进行保护，即SQL参数在执行时以受控方式添加到SQL查询的值，就是SQL检查每个参数来确保他对数据是正确的，而且按照字面意思处理，不是作为要执行的代码

    • 例子：参数在SQL语句中使用@来标记

      txtUserId = getRequestString("UserId");

      txtSQL = "SELECT * FROM Users WHERE UserId = @0";

      db.Execute(txtSQL,txtUserId);

      或者

      txtNam = getRequestString("CustomerName");

      txtAdd = getRequestString("Address");

      txtCit = getRequestString("City");

      txtSQL = "INSERT INTO Customers (CustomerName,Address,City) Values(@0,@1,@2)";

      db.Execute(txtSQL,txtNam,txtAdd,txtCit);

    • 下列示例展示在常见的Web语言中构建参数化查询
      • ASP.NET中的选择语句

        txtUserId = getRequestString("UserId");

        sql = "SELECT * FROM Customers WHERE CustomerId = @0";

        command = new SqlCommand(sql);

        command.Parameters.AddWithValue("@0",txtUserId);

        command.ExecuteReader();

      • ASP.NET中的插入语句

        txtNam = getRequestString("CustomerName");

        txtAdd = getRequestString("Address");

        txtCit = getRequestString("City");

        txtSQL = "INSERT INTO Customers (CustomerName,Address,City) Values(@0,@1,@2)";

        command = new SqlCommand(txtSQL);

        command.Parameters.AddWithValue("@0",txtNam);

        command.Parameters.AddWithValue("@1",txtAdd);

        command.Parameters.AddWithValue("@2",txtCit);

        command.ExecuteNonQuery();

      • PHP中的插入语句

        $stmt = $dbh->prepare("INSERT INTO Customers (CustomerName,Address,City)

        VALUES (:nam, :add, :cit)");

        $stmt->bindParam(':nam', $txtNam);

        $stmt->bindParam(':add', $txtAdd);

        $stmt->bindParam(':cit', $txtCit);

        $stmt->execute();

20.SQL数据类型

数据库表的每一列都需要有一个名称和数据类型，SQL在创建表时必须决定每列存储的数据类型，

数据类型是SQL了解每列中存储什么类型的数据的方法，数据类型也确定了SQL将如何与存储的数据进行交互，

数据类型在不同的数据库中有不同的名称、大小、细节

  • 数据类型以MySQL为例，主要是字符串、数字、日期时间。
  • 字符串：
char（size）固定长度字符串，可以包含字母、数字、特殊字符，size参数指定列的长度，默认1，最大为255.
varchar（size）可变的长度字符串，可以包含字母、数字、特殊字符，size参数指定最大字符串长度，默认1，最大65535
binary（size）类似于char，存储二进制字节字符串，size指定字节长度，默认1
varbinary（size）类似于varchar，存储二进制字符串，size指定最大列长度
tinyblob存储二进制大对象，最大长度为255字节
tinytext存储最大长度为255的字符串
text（size）存储最大长度为65535字节的字符串
blob（size）存储二进制大对象，最长为65535
mediumtext存储最大长度16777215字符的字符串
mediumblob存储二进制大对象，最长为16777215字节
longtext存储最长为4294967295字符字符串
longblob存储二进制大对象
enum（val1，val2，…）字符串对象，只能从预定值列表中选择1个值，最多65535个值，如果插入的值不在列表，就插入空值
set（val1，val2，…）字符串对象，只能从与定义的值列表中选择0或多个值，列表最多64个
  • 数字类型：所有的数字类型都有额外的选项，UNSIGNED 或 ZEROFILL。如果添加 UNSIGNED 选项，MySQL 不允许列使用负值。如果添加 ZEROFILL 选项，MySQL 还会自动将 UNSIGNED 属性添加到列中。
bit（size）位值类型，size参数指定每个值的位数，范围1-64
tinyint（size）非常小的整数，有符号-128到127，无符号0到255，size指定最大显示宽度255
bool布尔值，0为假，其余为真
boolean等同于bool
smallint（size）小整数，有符号-32768到32867，无符号0-65535，size参数指定最大宽度255
mediumint（size）中等整数
int（size）中等整数，最大宽度size为255
integer（size）等同于int（size）
bigint（size）大整数，最大显示size255
float（size，d）浮点数，size为指定总位数（已弃用）
float（p）fu点数，p为0-24为float，25-53则为double
double（size，d）标准浮点数，size指定总位数，d指定小数点后位数
double precision（size，d）等同于double（size，d）
decimal（size，d）标准的定点数，size指定总位数，d指定小数点后位数，size最大65，d最大30，默认size=10，d=0
dec（size，d）等同于decimal（size，d）
  • 日期与时间类型：
date日期，格式YYYY-MM-DD，范围为”1000-01-01“到”9999-12-31“
datetime（fsp）日期与时间，格式YYYY-MM-DD hh：mm：ss，支持范围”00：00：00“到”23：59：59“，可以添加default和on update来自动初始化和更新为当前日期
timestamp（fsp）时间戳，存储自”1970-01-01 00：00：00“到现在的秒数
time（fsp）时间，格式hh：mm：ss，范围‘-838：59：59’到‘838：59：59’
year四位格式年份，范围1901-2155，以及0000，MySQL8.0不支持两位格式的年份。
