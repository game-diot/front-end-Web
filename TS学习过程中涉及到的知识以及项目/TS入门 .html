interface Shape {

getArea: () => number;

}

class Rectangle implements Shape {

// using protected for these members allows access from classes that extend from this class, such as Square

public constructor(protected readonly width: number, protected readonly height: number) {}

public getArea(): number {

return this.width * this.height;

}

public toString(): string {

return `Rectangle[width=${this.width}, height=${this.height}]`;

}

}

class Square extends Rectangle {

public constructor(width: number) {

super(width, width);

}

// this toString replaces the toString from Rectangle

public override toString(): string {

return `Square[width=${this.width}]`;

}

}

TS特殊数据类型：

类型：any

  • any可以禁用类型检查并有效使用所有类型的类型
    • 例子：无any，会报错
      • let u = true
      • u = ‘string’
      • Math.round（u）
    • 设置any为特殊类型，禁用类型检查即可
      • let v：any = true
      • v = ‘string’
      • Math.round（v）
  • 由于any仅用了类型检查，可以避免报出错误，但不会解决错误，少使用

类型：unknown

  • unknown是any类型更安全的替代方案。
    • TS会阻止unknown使用类型
      • let w：known = 1
      • w = ‘string’
      • w = {
        runANonExistentMethod: () => {
        console.log("I think therefore I am");
        }
        } as { runANonExistentMethod: () => void };
      • if （typeof w ===‘object’ && w ！==null）{
      • (w as { runANonExistentMethod: Function }).runANonExistentMethod();}
  • unknown适用于不知道输入的数据类型情况，后续添加类型，需要类型转换，使用as关键字来表示属性或变量属于强制类型转换

类型：never，极少数使用，会报错

  • let x：never = true

类型：undefined&null

  • undefinde和null分别引用JS的undefined和null类型
    • let y：undefined = undefined

TS转换：

  • 有时处理类型时需要覆盖变量的类型，例如当库提供不正确的类型时
  • 强制转换时覆盖类型的过程

转换变量：as

  • 转换变量的直接方法时as关键字，将直接改变给定变量的类型
    • let x：unknown = ‘hello’；
    • console.log（（x as string）.length）
  • 强制转换实际上不会改变变量内数据的类型，例如变量x仍保存为数字，以下代码无法正常工作
    • let x：known = 4
    • console.log（（x ax string）.length）
  • TS会尝试进行类型检查转换，防止出现不正确的转换，例如，下面内容会引发类型错误，因为TS会进行转换数据，否则代码本身没有意义
    • console.log（（4 as string）.length）

转换变量：<>

  • 使用<>与as相同强制转换类型
    • let x ： knowen = “hello”
    • console.log（（ <string>x）.length）
  • 这种类型转换不适用于tsx，尤其处理React文件时

强制施法

  • 覆盖TS在转换时可能引发的类型错误，先将其转换为unknown，然后转换为目标类型
    • let x = “hello”
    • console.log（（（x as unknown）as number）.length），会返回未定义结果

TS的空值Null和Undefined：

  • TS有一个强大的系统来处理null或undefined值
  • 默认情况下null和undefined处理是禁用的，通过设置strictNullChecks为true启用

类型：null和undefined

  • null和undefined为原始类型，可以向其他类型一样使用，例如string
    • let value：string | undefined| null = null
    • value = ‘hello’
    • value = undefined
  • 启用strickNullChecks，Ts要求设置值，处分undefined明确添加到类型中

可选链式调用

  • 可选链式调用时JS特性，可以与TS的空值处理很好的兼容，允许以紧凑的语法访问对象上可能存在或不存在的属性，？.访问属性时，它可以与运算符一起使用

      • yard？：{
        • sqft：number；
      • }
    • }

      • const yardSize = house.yard？.sqft；
      • if （yardSize === undefined）{
        • console.log（‘NoYard’）
      • }else{
        • console.log（·yard is ￥{yardSize} sqft·）
      • }
    • }
    • let home：Home = {
      • sqft：500
    • }
    • printYardSize（home），结果为NoYard。

空值合并：

  • 空值合并时JS特性，也能与TS的空值处理很好的兼容，允许编写专门用于处理null或undefined的表达式，当表达式中可以出现其他假值但有效时，该功能很有用，可以与？？运算符一起在表达式中使用，类似于使用&&运算符
