创建和嵌套组件

  • React应用程序是由组件组成的，一个组件时UI（用户界面）的一部分，他有自己的逻辑和外观，可以小到一个按钮，大到一个页面
  • React组件是带有返回标签的JS函数，
  • export default关键字指定列文件中的主要组件，默认导出
    • 下例是声明并使用React组件
    • 声明MyButton组件

    function MyButton() {

    return (

    <button>我是一个按钮</button>

    );

    }

    • 嵌套到另一个组件

    export default function MyApp() {

    return (

    <div>

    <h1>欢迎来到我的应用</h1>

    <MyButton />

    </div>

    );

    }

使用JSX编写标签

  • React项目使用的标签语法被称为JSX，这个语法是可选的，但是多用与JSX
  • JSX比HTML更加严格，你必须闭合标签，如<br />；同时组件也不能返回多个JSX标签，必须将多个标签包裹到一个共享的父级中，<div>或者空的<>包裹
    大量的HTML标签移植到JSX，建议使用在线转换器工具

    function AboutPage() {

    return (

    <>

    <h1>关于</h1>

    <p>你好。<br />最近怎么样？</p>

    </>

    );

    }

添加样式

  • 在React中可以使用className来指定一个CSS的class，他与HTML的clas属性的工作方式相同
    <img className = ‘photo’>
  • 也可以在一个单独的CSS文件中为他编写设置样式styles
    /* 在你的 CSS 文件中修改 */

    .avatar {

    border-radius: 50%;

    }

  • React并没有规定你如何添加CSS文件，最简单的方式就是使用HTML的<link>标签，可以使用其他的弓箭工具或者框架

显示数据（就是用大括号{}传递变量）

  • JSX会让你把标签放到JS中，大括号可以在代码中嵌套一些变量展示给用户，下例会显示user.name
    return (

    <h1>

    {user.name}

    </h1>

    );

  • 也可以将JSX属性‘转义到JS中’，但是必须使用大括号而非引号，例如className=‘avatar’，将avatar字符串传递给className，作为CSS的class，但是src={yser.imageUrl}会读取JS的user.imageUrl变量，然后将该该值作为src属性传递
    return (

    <img

    className="avatar"

    src={user.imageUrl}

    />

    );

  • 也可以将更为复杂的表达式放入JSX的打括号内，例如字符串拼接
    const user = {

条件渲染

  • React没有特殊的语法来编写条件语句，因此使用的就是普通的JS代码，例如使用if语句根据条件引入JSX
    可以使用条件?运算符代替if、不需要else可以使用逻辑运算符&&

    let content;

    if (isLoggedIn) {

    content = <AdminPanel />;

    } else {

    content = <LoginForm />;

    }

    return (

    <div>

    {content}

    </div>

    );

    <div>

    {isLoggedIn ? (

    <AdminPanel />

    ) : (

    <LoginForm />

    )}

    </div>

    <div>

    {isLoggedIn && <AdminPanel />}

    </div>

更新界面

  • 希望组件记住一些信息并展示出来，比如一个按钮被点击的次数，需要在组件中添加state
    • 首先在React引入useState
      • import {useState} from ‘react’；
    • 在组件声明state变量
      • function MyButton（）{
        • const 【count，setCount】 = useState（0）；
        • …..}
      • 这样就可以在useState中获得当前的state（count）以及用于更新他的函数（setCount），可以更改变量函数名字
    • 第一次显示按钮，count为0，因为将0传递给了useState（），改变count也就是state时，调用setCount（）并传递新的值给他，例如店家按钮计数器将递增
      function MyButton() {

      const [count, setCount] = useState(0);

      function handleClick() {

      setCount(count + 1);

      }

      return (

      <button onClick={handleClick}>

      Clicked {count} times

      </button>

      );

      }

      React会多次调用你的组件函数，通过每次点击

使用Hook

  • 以use开头的函数被称为Hook，useState时React提供的一个内置Hook，可以在API参考中找到其他内置的Hook，可以通过组合现有的Hook来编写属于自己的Hook
  • Hook比普通函数更为严格，只能在组件或者其他Hook的顶层调用Hook，如果想在一个循环或者条件判断中使用sueState，需要提取一个新的组件并在内部使用它

组件间共享数据

  • 在前方示例中，每个MyButton都有自己独立的count，当每个按钮点击时，只有被点击的按钮count才会加一
  • 组件间共享数据并一起更新时必须掌握的，就按钮而言，点击任意一个都会count加一，需要将各个按钮的state向上一级到包含所有按钮的组件中，这里是MyApp
  • 共享数据代码如下，以Button实例
    export default function MyApp() {

    const [count, setCount] = useState(0);

    function handleClick() {

    setCount(count + 1);

    }

    return (

    <div>

    <h1>独立更新的计数器</h1>

    <MyButton />

    <MyButton />

    </div>

    );

    }

    function MyButton() {

    // ... 我们将把代码移动到这里 ...

    }

  • 将MyApp中的点击事件处理函数以及state向下传递到每个MyButton中，这里使用JSX大括号传递变量信息，
    export default function MyApp() {

    const [count, setCount] = useState(0);

    function handleClick() {

    setCount(count + 1);

    }

    return (

    <div>

    <h1>共同更新的计数器</h1>

    <MyButton count={count} onClick={handleClick} />

    <MyButton count={count} onClick={handleClick} />

    </div>

    );

    }

    function MyButton({ count, onClick }) {

    return (

    <button onClick={onClick}>

    点了 {count} 次

    </button>

    );

    }

  • 整个流程为：
    • 当你点击按钮时，onClick 处理程序会启动。每个按钮的 onClick prop 会被设置为 MyApp 内的 handleClick 函数，所以函数内的代码会被执行。该代码会调用 setCount(count + 1)，使得 state 变量 count 递增。新的 count 值会被作为 prop 传递给每个按钮，因此它们每次展示的都是最新的值。这被称为“状态提升”。通过向上移动 state，我们实现了在组件间共享它。
